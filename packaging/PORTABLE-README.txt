微窗助手 V1.1.6（绿色免安装版）

使用方法：
1. 解压整个文件夹。
2. 双击 wechat_duokai.exe。
3. 在最右侧设置微信和企业微信共用的目标数量，再点击对应的“启动 / 补开”按钮。
   数量卡片标题下会显示“微信与企微共用”，修改后会自动保存。
4. 共用数量会自动保存；如果关闭了其中一个实例，再次点击对应客户端即可只补开缺少的实例。
5. 点击右上角“日间/夜间”可即时切换；也可在右下角“设置”中选择跟随系统、日间或夜间。
6. 如果没有自动找到客户端，点击卡片中的“…”选择官方 EXE；必须通过腾讯数字签名验证。
7. 窗口可从 901×513 自由缩放到最大化；全部内容会统一按比例放大，不出现外层滚动条。
8. 左下角两行实时显示当前微信和企业微信的根窗口数量。
9. 每个客户端卡片都有“全部退出”；确认后只退出当前 Windows 会话中、路径与已验证官方客户端完全一致的窗口，不会注销账号。
10. 设置中的“本地诊断”只在本目录的 data\diagnostics 文件夹生成报告，不会自动上传。
11. 设置中可启用当前用户开机自动启动，并可选择自动启动时最小化；只启动助手，不会自动打开客户端。
12. 设置中可关闭每日版本检查，也可选择发现新版后自动下载并校验；安装程序运行前仍需用户确认。
13. 自动检查最多每天一次并错峰进行，手动检查始终立即执行；已完整验证的更新包可安全复用。
14. 设置、主题、更新检查状态、诊断和注册表恢复日志都保存在本目录的 data 文件夹，不向 AppData 新增运行文件。

完全卸载：
- 双击 wechat_duokai-cleanup-v1.1.6.exe。
- 选项一会删除已安装程序和全部发布包，但保留带安全标记的源码目录。
- 选项二会永久删除安装程序、发布包和带安全标记的源码目录，需要额外勾选和确认。
- 如果绿色版不在源码/发布目录内，清理器只会删除能通过专用标记校验的绿色版目录，不会猜测或删除其他目录。

安全说明：
- 本工具不会上传聊天记录、账号、文件或诊断报告。
- 启用每日检查时，自动网络请求优先读取本项目 GitHub Release 的静态 update-manifest.json；可在设置中关闭。
- 自动检查成功后缓存 24 小时并错峰 30–300 秒，失败按 1/6/24 小时退避；手动检查不受限制。
- 版本号和附件摘要主路径不使用公共 REST API；不会因共享网络的每小时 60 次未登录 API 配额耗尽
  而把正常更新误报成“检查失败”。
- 当当前进程配置了规范 HTTPS_PROXY/HTTP_PROXY 时，检查和下载会使用同一代理；代理地址和凭据
  不写入设置、诊断或日志，GitHub 请求固定使用 TLS 1.2。
- 默认只有用户确认一键更新后才下载；也可主动开启“发现后自动下载并校验”。可取得 GitHub 附件摘要时
  作为额外交叉核验，API 暂不可用时仍强制静态清单、SHA256SUMS 和下载文件一致；自动下载不会静默安装。
- 开机自动启动只写入当前 Windows 用户的标准 Run 启动项。绿色版移动后修复自有路径；同名外部值会
  被保留，清理器也只删除与已验证目标目录精确匹配的本项目启动项。
- 本工具不注入 DLL，不修改微信/企业微信程序文件；只有用户点击对应“全部退出”并确认后，才关闭当前会话中精确路径匹配的客户端进程。
- 补开功能只会关闭已知的微信/企业微信单实例锁句柄。
- 企业微信注册表临时状态只有在未被第三方更改时才恢复；第三方写入的新值会被保留。
- 修改注册表前会先把恢复事务强制写入 data\recovery；异常退出或断电后，下次启动会安全核对并恢复。
- 主程序需要与 WechatDuokai.Core.dll 放在同一文件夹，请勿只单独复制 EXE。
- 未提供代码签名证书，因此本版本没有数字签名；请用 SHA256SUMS.txt 核对文件哈希。
- 审计期间曾出现一次通用启发式云端告警；后续未发现恶意链条。请先阅读随包提供的
  SECURITY-AUDIT.md 和“完整安全审计与卡巴斯基告警调查报告.txt”，不要关闭安全软件或设置永久白名单。
- 正式包的卡巴斯基结果与病毒库日期以同版本 Release 日志为准。
- 不同客户端版本可能调整单实例机制；请先用测试账号验证，并遵守相关软件许可与组织规定。
