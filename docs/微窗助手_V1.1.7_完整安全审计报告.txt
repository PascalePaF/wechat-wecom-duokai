微窗助手 V1.1.7 安全审计报告
==============================

文档编号：WD-V117-SECURITY-20261022
审计日期：2026-10-22
项目地址：https://github.com/PascalePaF/wechat-wecom-duokai

一、新增 QQ 功能
----------------
QQ 仅从用户指定、本机注册表、已运行进程及常见官方安装目录中寻找候选 QQ.exe。
启用前继续校验文件名、产品身份与有效腾讯 Authenticode 签名；不能只靠文件名通过。
实例统计限当前 Windows 会话、所选文件完整路径，并按父子进程关系归并根实例。
QQ 直接运行官方程序，不调用微信/企微的句柄解锁器，不写 QQ 注册表、不注入 DLL、
不修改程序文件，也不读取 QQ 聊天、账号、联系人或登录凭据。

本机 QQ 9.9.35.52892 的一次启动测试观察到根实例从 1 变为 2；未验证所有版本或真实账号登录。
目标数量是助手控制范围，不是 QQ 官方承诺。未成功补开时显示实际结果，不使用更激进的绕过手段。

二、主题界面与安装边界
----------------------
旧式系统提示/确认、文件选择及文件夹选择入口改用 WPF 共用主题组件，主程序、安装器、
清理器与清理工作进程均使用相同日夜配色。新选择器只决定候选路径，仍须经过原有官方
程序签名校验或安装路径结构/标记校验。安装覆盖、更新执行与“全部退出”仍须用户确认。
清理工作进程继承清理器当前主题，但删除目标仍由经校验的清理计划决定，不由 UI 路径文本决定。

三、隐私与网络
--------------
本版没有增加服务器、遥测、后台上传或账号接口。版本检查仍访问本项目 GitHub Release；
是否每天自动检查和是否自动下载可在设置中分别选择。诊断报告只写到程序目录 data\diagnostics。
没有发现新增读取聊天数据库、凭据、剪贴板、摄像头或屏幕的代码路径。

四、验证与限制
--------------
自动测试覆盖 QQ 直启与伪装程序拒绝、主题组件、三卡片布局、既有安装/清理/更新及
企业微信注册表恢复。正式发布还需对应源码标签、干净 Windows CI、SHA256SUMS、SBOM、
同版本 Kaspersky 原始扫描日志核对。安全软件未检出不等于无风险。

项目本身尚无商业 Authenticode 签名；如果安全软件明确报毒，应先隔离并核对来源、哈希、
检测名称和行为，不能直接加入白名单。不要把此报告理解为腾讯对本项目或多开的认可。
