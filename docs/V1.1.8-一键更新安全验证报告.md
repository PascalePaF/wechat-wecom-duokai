# V1.1.8 更新与安装安全验证

更新仍只接受本项目 GitHub Release 的规范附件名称、HTTPS 地址、限定大小及 SHA-256 交叉校验。执行安装器前重新持锁计算哈希，目标目录与版本需匹配更新计划。

本版增加覆盖整个更新检查与下载操作的取消时限，包括收到响应头后的流式正文。超时只终止未完成操作，不运行未验证的包。GitHub API 正文也设置大小上限。

更新缓存及更新交接计划拒绝上级目录联接和文件符号链接；下载及计划临时文件采用随机名称及 CreateNew，提交使用原子替换，减少中断造成的状态丢失。交接计划读取前同样检查路径，避免安装器接受重定向文件。

回归包括模拟响应头正常但正文永久停滞、用户取消、未篡改缓存复用、摘要不一致拒绝、安装失败回滚与数据保留。全新 Windows CI 继续验证完整安装、手动升级和卸载链路。

本版不修改旧 Release 的既有二进制文件，避免让现有更新摘要失效。新安装包、绿色包、SHA256SUMS 和 update-manifest.json 由同一次 Windows 构建产生，并在发布前逐项核对。
