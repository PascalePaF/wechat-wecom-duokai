# V1.0.5 UI 回归矩阵

验证日期：2026-09-16（Asia/Tokyo）

## 验证标准

- 主窗口最小尺寸固定为 901×513，主界面和设置页均不出现横向或纵向滚动条；
- 放大后文字、图标、按钮、间距、圆角和阴影使用同一比例缩放并填满可用区域；
- 微信/企业微信卡片保持左侧，目标窗口数保持最右侧；
- 左下角两行分别显示微信与企业微信窗口数，文本左对齐且不与状态信息重叠；
- “设置”是右下角最右侧按钮；进入设置后变为“返回”，页脚仍保持可见；
- 设置页完整显示“跟随 Windows / 日间 / 夜间”、启动检查开关、发布页和立即检查按钮；
- 日间与夜间主题具有足够对比度；文字、图标和阴影不使用位图拉伸；
- 安装器、完成态和独立清理器继续具有原生可移动标题栏。
