## V1.0.6 重点断言

| 场景 | 预期 | 结果 |
| --- | --- | --- |
| 主界面 901×513 | 微信与企微两组减号、数量、加号完整显示 | 通过 |
| 两项目标 | 标签和无障碍名称明确区分微信/企业微信 | 通过 |
| 最小尺寸 | 应用卡片、独立数量、双行实时计数和页脚按钮均不裁切 | 通过 |
| 放大/最大化 | 控件、文字、圆角、阴影与间距同步放大并填满屏幕 | 通过 |
| 超宽屏 | 目标数量仍在最右侧，不退化为顶部小卡片 | 通过 |
| 设置页 | 跟随系统、日间、夜间、版本检查和返回入口完整 | 通过 |
| 安装器 | 自选路径、运行中覆盖确认和安装后明确启动确认不回归 | 通过 |
| 清理器 | 两种删除范围和高风险源码确认不回归 | 通过 |
| 日间/夜间 | 边框、文字、按钮和状态色对比度无明显异常 | 通过 |

根节点内，没有外层 `ScrollViewer`，左右卡片在所有尺寸下保持同一行。
