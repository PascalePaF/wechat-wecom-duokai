# V1.1.7 更新与安装安全验证报告

文档编号：`WD-V117-UPDATE-20261022`

## 范围

本版没有改变更新来源、静态 Release 清单优先策略、下载 URL 白名单、长度与 SHA-256 校验、用户执行确认、安装事务回滚和绿色版身份标记。安装器的目录选择与确认弹窗改用统一主题组件；清理工作进程会继承当前日间/夜间选择。

## 验证点

1. 安装包、绿色版、独立清理器继续分别编译，且版本号与清单保持一致。
2. 安装目录仍须通过原有路径、链接、源码/发布包标记和非空目录验证；新选择器不绕开 `InstallerEngine` 的后端校验。
3. 自动更新仍需核对静态清单、校验文件和安装包哈希；执行安装前仍由用户确认。自动下载不会静默安装。
4. 清理计划继续验证父进程、工作进程路径与目标标记；工作进程只在用户确认后运行，其提示框现在使用与清理器相同的主题。
5. 本地 Release 构建、完整测试、全新 Windows CI、发布附件哈希与扫描日志以最终同版本结果为准。

未增加 QQ 相关网络请求、下载源或后台上传。QQ 只在用户点击对应卡片时尝试从经签名验证的本地官方路径启动。
