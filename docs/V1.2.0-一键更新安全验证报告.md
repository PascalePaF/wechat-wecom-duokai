# V1.2.0 更新与安装验证范围

不改变更新网络来源或核验协议。继续读取本仓库正式静态清单，要求文件大小、SHA256SUMS 与下载一致，并在安装前确认及再次校验；保持失败回滚、设置保留。

安装版、绿色版、清理器来自同一成功 Windows CI 的确切提交。发布前核对上传附件摘要及 SBOM、扫描正式原件；发布后验证旧版本号发现 V1.2.0、下载与哈希链路，不执行安装器。

主题仍经明确白名单传递，没有远程主题和新增凭据。安装/绿色身份、目录标记、路径重定向拒绝及清理边界保持回归。

首次安装回滚在暂存被独占占用时保持中断标记，不把非空目录遗留为无法重试的未标记状态。确定性测试锁住暂存文件、注入中断，再释放锁并原目录重试，要求半安装不能运行、重装后完整有效。
