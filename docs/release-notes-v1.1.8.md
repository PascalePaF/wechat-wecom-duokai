# 微窗助手 V1.1.8

发布日期：2026-10-30

本版集中修复更新连接停滞、本地数据目录边界和公开资料隐私问题，保持 QQ、微信、企业微信三卡片与日夜主题布局。

- 更新检查增加覆盖响应正文的总时限，安装包下载也受总时限约束。慢速或停滞连接会结束并提示重试，用户取消仍能立即生效。
- GitHub API 元数据改为限量流式读取，拒绝超出限制的响应。
- 客户端签名验证在 Windows 信任验证后，精确核对证书中的腾讯法定组织，拒绝仅在名称中夹带 Tencent 的发布者。
- 数据目录逐级拒绝符号链接和目录联接；诊断、设置、更新缓存及注册表恢复日志增加路径保护。写入使用独立临时文件与原子替换。
- 本地诊断默认隐藏完整路径，同一秒多次生成报告不会覆盖。设置页入口显示为“脱敏报告”。
- 当前公开资料中的本机路径改为占位符；新截图使用统一演示数据；发布构建映射编译源路径，并增加发布隐私检查。

## 下载与核验

提供安装版、绿色免安装版和独立清理器。SHA256SUMS、静态更新清单与 SPDX SBOM 一起发布。程序内检查更新可获取本版，执行安装前仍需确认。

本项目未购买公共代码签名。Windows、杀毒软件或组织策略仍可能提示未知发布者；不要关闭防护或永久忽略明确告警。扫描未检出不能替代软件安全证明。

## 范围说明

本版修复与清理不改写既有 Git 提交和标签，也不静默替换旧 Release 的二进制附件。历史低敏感度路径信息可能仍可从旧记录访问；详见全项目自查报告。任何已经被他人下载的副本均不由本仓库控制。

多开兼容性仍取决于腾讯客户端和组织策略；本版不声称对所有客户端版本或账号环境做过实机验证。
