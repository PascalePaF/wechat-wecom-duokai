# V1.1.8 UI 回归矩阵

主界面保持 QQ、微信、企业微信顺序与共用目标数量；设置中的诊断入口改为“脱敏报告”。

运行 `scripts/capture-ui-matrix.ps1` 生成 23 个本版截图：主界面最小尺寸、1280×720、1920×1080 和 3440×1392，设置、介绍、安装前后、清理器、信息/确认弹窗、文件/文件夹选择器的日间与夜间状态。

所有样例在截图测试层注入统一演示数据：客户端路径采用 `C:\Apps\Tencent`，安装目录采用 `C:\Apps\WechatDuokai`；文件列表只显示演示客户端目录，不显示开发机文件夹。该注入只作用于截图测试，不改变正常软件的路径选择和客户端检测。

自动化布局检查继续覆盖可移动原生标题栏、最小窗口、比例缩放、三卡片对齐、设置导航和主题资源。历史版本的界面矩阵文字记录保留，旧图片退出当前默认分支以减少本机路径暴露。
