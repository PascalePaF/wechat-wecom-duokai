# V1.0.11 — 任务栏图标同步与全项目自查

V1.0.11 修复了程序内已经换成新 Logo，但 Windows 任务栏或旧快捷方式仍可能显示旧图标的
问题。本版没有再更换品牌图形，而是把已经确定的微信绿 / 企微蓝双窗口 Logo 完整接入
Windows 窗口、任务栏、EXE、桌面快捷方式、开始菜单、安装器和清理器。

## 本版变化

- 主程序、安装器和清理器的 WPF 窗口显式绑定 `favicon.ico`，不再依赖 Windows 猜测窗口图标。
- 为三种进程设置稳定、互不混用的 AppUserModelID；桌面与开始菜单快捷方式也写入与目标进程一致的身份，避免固定后出现旧图标或重复任务栏按钮。
- 安装、覆盖更新、快捷方式迁移与清理完成后，主动通知 Windows Explorer 刷新精确文件与图标缓存。
- 绿色版每次启动也会对当前 EXE 发出图标变更通知，覆盖同路径旧文件后无需手工重启 Explorer。
- 新增自动图标断言：三个窗口必须有显式图标，三个发布 EXE 必须同时包含微信同类绿和企微同类蓝。
- 版本号收拢到 `Directory.Build.props` 一个来源；界面、文件属性、安装包名和更新请求自动从程序集读取。
- 发布脚本新增版本、Windows 清单与四个二进制文件的一致性门禁，任一漏改就停止组包。
- 未处理 UI 异常不再让程序带着不确定状态继续运行；提示用户后会有序退出。
- 完成源码、构建、更新、删除、注册表、网络、持久化、进程和资源的全项目自查，未发现后台上传隐私或恶意代码。

## 安全边界

- 不注入 DLL，不修改微信/企业微信文件，不读取聊天、账号、联系人或凭据。
- 图标刷新只调用 Windows Shell 通知，不重启 Explorer，不删除 Windows 图标缓存数据库。
- 一键更新仍只接受本项目正式 GitHub Release，并强制 GitHub digest、`SHA256SUMS.txt`
  与本机文件三方 SHA-256 一致。
- 项目仍未使用付费 Authenticode 证书；请从正式 Release 下载并核对哈希、CI、SBOM 和扫描证据。
