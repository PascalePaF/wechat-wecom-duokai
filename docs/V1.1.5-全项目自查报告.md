# 微窗助手 V1.1.5 全项目自查报告

文档编号：`WD-V115-AUDIT-20260922`

## 结论

V1.1.5 新增两组明确、可关闭的本地功能：当前用户开机自动启动，以及发现新版本后自动下载并校验。
源码复核与自动测试未发现后台上传隐私、广告遥测、账号/聊天/凭据采集、远程控制、代码注入、客户端
文件修改或隐藏载荷。自动下载不会静默安装；启动项不会自动打开微信或企业微信。

## 设置项取舍

本轮同时检查了设置页是否还缺少常用项目。最终只增加：

- 开机后自动启动；
- 自动启动时最小化；
- 发现更新后自动下载并校验；
- 上次成功与下次自动检查的只读状态。

未加入“启动后自动打开客户端”“静默安装”“后台常驻托盘”“自动结束客户端”等开关，因为这些会改变
用户可见行为、扩大后台能力或让设置页变复杂，不属于本轮必要范围。

## 启动项安全复核

- 使用 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，不使用服务、计划任务、驱动或管理员自启。
- 值名固定，命令由程序生成，不接受用户拼接参数；路径总是完整绝对路径并用双引号包裹。
- 开启前要求当前目录是本项目带专用标记的正式安装版或绿色版；开发输出目录被拒绝。
- 已有同名值若不是精确的 `wechat_duokai.exe --autostart`，视为第三方冲突，不覆盖。
- 绿色版移动只覆盖能够证明属于本项目的旧格式值；清理只删除与已验证清理目标完全一致的 EXE。
- 关闭设置时如果同名值属于第三方，只停止本程序后续自启意图，不删除第三方内容。

## 更新链安全复核

- 固定 GitHub 仓库、规范 Release URL、TLS 1.2、静态清单优先和可选 API 摘要交叉核验不变。
- 自动下载默认关闭，只下载 setup 与 SHA256SUMS；不下载或运行脚本、DLL、配置更新或任意 URL。
- 缓存复用需要外部可信摘要、校验文件唯一记录、精确大小与本机文件哈希全部一致。
- setup 启动前再次哈希；安装器使用更新计划、父进程身份、专用目录标记、同卷暂存、备份和回滚。
- 网络失败只影响更新体验；多开、补开、实时计数、分端退出和本地诊断不依赖更新服务。

## 文件、注册表、进程与隐私复核

- 除用户主动开启的当前用户 Run 值、安装版卸载登记和快捷方式外，所有持久文件仍在应用目录。
- 企业微信 `multi_instances` 的写前事务、断电恢复和外部冲突保护未改。
- “全部退出”继续要求确认，只处理当前 Windows 会话中与已验证客户端路径完全一致的进程。
- 不注入 DLL，不创建远程线程，不写微信/企微内存、程序文件、聊天数据库或账号资料。
- 诊断和恢复日志不自动上传；GitHub 只接收普通 HTTPS 请求必要的 IP 和 User-Agent。
