微窗助手 V1.1.4 完整安全审计报告
=================================

文档编号：WD-V114-SECURITY-20260921
审计日期：2026-09-21
项目地址：https://github.com/PascalePaF/wechat-wecom-duokai

一、结论
--------

V1.1.4 只修复右侧“目标窗口数”卡片的视觉回归。未发现后门、隐蔽上传、聊天/账号/凭据采集、远程控制、
广告遥测、静默执行、DLL 注入或隐藏载荷。多开核心、进程退出、企业微信注册表事务、安装/清理、更新与
网络代码均未因本轮界面修复改变。

二、UI 回归原因
--------------

V1.0.10 的数量卡片使用 Auto / 18 / 76 / 12 / Auto 五段布局并整体垂直居中。V1.1.0 为对齐左右内部
轨道，将其改成与应用卡片相同的四段比例布局，同时把“微信与企微共用”和“数量会自动保存”合并到底部。
这使卡片信息层级变弱，中间产生较大空白。V1.1.4 恢复 V1.0.10 内部布局，但保留左右外框等高。

三、敏感能力复核
----------------

- 微信/企业微信定位、腾讯签名验证、根实例统计和精确锁处理未改。
- 企业微信 multi_instances 落盘事务、断电恢复和外部冲突保护未改。
- “全部退出”仍需确认，只处理当前会话和已验证精确路径。
- 诊断仍只写 data\diagnostics，不自动上传。
- 所有设置、更新状态、下载与恢复证据仍位于程序目录 data。
- GitHub 更新仍使用静态清单主路径、TLS 1.2、规范环境代理和多重 SHA-256。
- 安装和一键更新仍需用户确认；失败时不执行未验证文件。

四、发布验证
------------

发布前要求本机测试、干净 Windows CI、清单和哈希复核、SPDX 2.2 SBOM、正式 CI 原件卡巴斯基扫描，
并在不可变 GitHub Release 发布前比对全部附件的服务端 digest。

五、剩余限制
------------

项目未商业签名，安全软件仍可能根据低信誉、句柄或注册表行为给出启发式提示。反病毒未检出是重要证据，
但不是绝对安全保证；用户应只从正式 Release 下载并核对 SHA-256、源码、CI、SBOM 和同版本扫描日志。

最终判断：V1.1.4 恢复 V1.0.10 数量卡片视觉，不扩大隐私、权限、网络、进程或文件操作范围。
