# 微窗助手 V1.1.6 版本说明

发布日期：2026-09-23

V1.1.6 是可靠性修复版。主界面布局、目标窗口数量、多开与补开方式不变。

## 修复与改进

- 自动检查更新在助手持续运行期间按本地 24 小时计划继续执行；关闭开关后不再启动尚未进行的检查，重新开启时会检查是否已到期。仍使用 30–300 秒启动错峰及失败退避，不增加遥测。
- 开机启动项区分当前安装版、绿色版及同一绿色版移动前的路径。另一份副本的启动项默认保留；用户可在设置中明确确认切换。开机最小化后再次点击快捷方式，会唤回已经运行的窗口。
- 设置文件改为同目录写穿暂存、替换和备份。旧设置在替换成功前保持原样；主文件缺失时可从备份读取。
- 普通安装和手动覆盖改用与一键更新相同的暂存、逐文件备份及异常回滚流程。安装中断标记阻止启动可能不完整的程序；重新运行正式安装包可完成中断的安装。
- 增加长时间运行更新检查、双副本启动冲突、确认式切换、设置备份恢复、窗口唤回和手动安装故障注入测试。
- 开放项目的 GitHub Issues，并提供不会要求公开账号或聊天内容的故障与建议表单。

## 安全与使用边界

更新包仍须完成既有 SHA-256 验证，执行安装仍须用户确认；本版没有新增后台上传、静默安装或更改微信/企业微信程序文件的行为。启动项仍只写入当前用户的 Windows `Run` 项，不安装服务或驱动。

如果上次安装因断电或进程意外终止而留下“安装未完成”提示，请重新运行从本项目 GitHub Release 获取的正式安装包，并选择原安装目录。程序会在安装完成前阻止打开不完整的助手文件。

项目未购买 Windows Authenticode 商业代码签名；安全软件的启发式提示仍应结合官方 Release、SHA256SUMS、源码、CI 与同版本扫描日志判断，不建议盲目忽略明确报毒。
