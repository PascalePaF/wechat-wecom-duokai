微窗助手 V1.2.0 安全边界与回归报告
审计日期：2026-11-04

一、本版修复
旧版只处理精确主 EXE，并以一次瞬时根实例快照判断退出，未处理不同名称的关联后台。新流程正常关闭后核验并结束关联后台，有限重试、捕获迟到子进程，并要求连续三个空样本才确认完成。
结果区分可见窗口、已核验后台、访问受限、未核验候选和复查异常；权限受限或检查失败不视为成功。

二、安全边界
仅处理当前用户 SID 和 Windows 会话中的目标主程序；辅助程序须在有限白名单、腾讯签名有效，并有受创建时间约束的已核验父子链。
微信插件可位于官方用户插件目录，因此不简单要求与主 EXE 同目录。通过签名和持有原生句柄的祖先证据纳入，未证明归属时不全局结束同名插件。
使用同一个已核验句柄终止/等待目标，核对 PID、创建时间、路径、用户和会话；核验期间持有只读文件租约。已捕获孤儿身份仅在本次助手运行内保留供重试，不新增含路径/PID的持久跟踪库。
先请求正常关闭，再结束剩余目标；不关闭安全软件、不添加排除、不自动提权、不修改客户端文件或删除聊天。

三、其他检查
启动恢复异常或无效返回转为安全失败，并阻止新的企微临时注册表会话。生命周期取消后不再显示启动/退出结果。
主题循环仍经明确枚举与原有保存保护；保存失败仅临时应用并提示。诊断仅新增计数，不添加账号、聊天、令牌、命令行或完整路径。
保持限量读取、路径重定向拒绝、法定腾讯组织校验、网络正文时限/大小边界、更新哈希/确认/回滚及注册表外部冲突/断电恢复。
首次安装回滚遇到暂存占用时，保留安全中断标记以阻止半安装程序运行并允许原目录重试。清理只作用于已拥有暂存目录，增加有限重试与路径重定向复核；不扩大删除范围。

四、验证与限制
覆盖逻辑边界与自行创建的真实隔离进程：无关同名后台保留、退出时新生子进程捕获、PID/出生时间/路径/用户不符拒绝，以及取消、权限和异常失败。隔离测试仅通过测试可见的信任替身识别自建样本，生产始终验证腾讯签名。
未对用户正在使用的 QQ、微信、企微账号批量退出；本机实际客户端仅作只读进程与签名检查。测试不能证明全部腾讯版本均兼容。
未知程序不扩大处理范围，权限/组织保护不绕过；如实报告残留，不承诺所有后台都可强行结束。
发布核对成功 Windows CI 原件、哈希、更新清单和 SBOM，并由卡巴斯基扫描，以同版本日志为准；不作绝对无漏洞/无病毒承诺。旧提交和不可变 Release 不改写。
