# V1.1.11 视觉改版与回归记录

日期：2026-10-31

- 将万圣节主题从配色扩展为标识、内存窗口图标、背景场景、卡片/边框、按钮、输入控件和数量控件的完整外观。
- 共享实现编译到主程序、安装器和清理器，避免各界面分别维护不同图形；无新第三方依赖。
- 普通主题恢复经典图标、纯色画刷、原有边框与尺寸；软件在磁盘上的品牌图标不变。
- 装饰限制在标题栏内容空位与外侧边缘，不参与命中测试或焦点；无自动动画，不以视觉效果扩展权限。
- 核对渐变最弱处的按钮对比度及实际文字边界，检查五个主题选项、小窗口和超宽屏缩放。
- 修复路径选择器窄按钮内边距导致的文字裁切；临时测试目录清理复用有限重试，避免短暂文件占用使正常回归偶发失败。
- 原有安全和安装回归继续执行，最终产物由全新 Windows CI 构建并扫描，公开截图使用演示路径。

图标缓存与固定快捷方式由 Windows 管理；不承诺每一种固定/分组状态都采用活动窗口图标，也不通过改写用户固定项来强制刷新。
