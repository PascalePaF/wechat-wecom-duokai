## 自动断言

- 三个 WPF 窗口必须保留原生标题栏、拖动、最小化、最大化和自由调整尺寸。
- 三个 WPF 窗口的 `Window.Icon` 必须非空，防止任务栏回退到旧图标或默认图标。
- 主程序、setup 和 cleanup 的原生 EXE 图标必须同时包含绿色与蓝色的有效像素。
- 安装器生成的 `.lnk` 必须携带与目标进程一致的 `System.AppUserModel.ID`，并可从快捷方式属性库读回。
- 主窗口最小尺寸为 `901×513`；扩大时所有文字、图标、按钮、间距、阴影与卡片按同一比例填满窗口。
- 夜间绿色、蓝色、图标背景和边框继续受舒适亮度上限约束。
- 设置页、软件介绍、诊断、发布版本、检查更新与一键更新入口保持完整。
- 左下角微信/企业微信实时计数保持两行、左对齐；右下角“设置”保持最右侧。

## 人工检查要点

- 标题栏左上角、Alt+Tab 缩略图与任务栏按钮使用同一绿蓝 Logo。
- 覆盖安装后原快捷方式指向未变，Windows 会在刷新通知后重读当前 EXE 图标。
- 已手工固定的历史任务栏项由 Windows 管理；如系统仍保留旧固定项，取消固定后再从新快捷方式固定即可。
