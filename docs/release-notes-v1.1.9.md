# 微窗助手 V1.1.9

发布日期：2026-10-31

## 万圣夜与独立主题页

- 设置新增“主题”选项卡，跟随系统、日间、夜间、万圣夜四张预览卡集中管理。顶栏主题按钮直达主题页，选择即时生效并自动记忆。
- 万圣夜采用低亮度紫黑、柔和南瓜橙与矢量南瓜点缀，不替换产品 Logo，不改变 QQ、微信、企业微信的品牌图标。
- 主程序、安装器、清理器、确认弹窗和路径选择器使用一致主题；一键更新传递当前主题，不再把季节主题降为浅色。
- 主题始终由用户主动选择，不按日期自动切换，不从网络下载主题或脚本。

## 修复与加固

- 修复主题写入失败仍提示“已保存”的问题，保留临时预览并明确提示检查写入权限。
- 主题、配置、更新状态、标记和恢复/清理计划改为有大小上限的读取；异常大文件不会无限占用内存，支持已有设置备份恢复。
- 修复窗口在启动恢复任务完成前关闭时，后续回调可能重启定时器或访问已释放取消源的问题。
- 季节主题使用暗色原生标题栏和低亮度图标底色；旧日夜主题、窗口最小尺寸、比例布局与共享目标数量保持不变。
- 修复全局正文样式覆盖按钮文字前景色的问题，使暖橙主按钮采用正确的深色文字，退出等按钮也按各自主题资源显示。

## 核验与边界

正式文件由全新 Windows GitHub Actions 构建，提供 SHA-256、静态更新清单、SPDX SBOM、回归与安全报告；发布前扫描最终原件。

本项目没有公共代码签名；扫描未检出不等于绝对安全。旧提交、标签和不可变 Release 未被改写，历史副本仍可能保留低敏感度目录名称。腾讯客户端兼容性仍受版本与组织策略影响。
