# V1.0.7 — 程序内检查与一键安全更新

V1.0.7 在原有版本检查基础上加入用户确认的一键更新。安装版和绿色免安装版都可以在设置页完成
“检查 → 下载 → 校验 → 覆盖 → 重启”，并保留程序目录 `data` 中的全部设置与本地记录。

## 新功能

- 设置页新增“一键更新 Vx.x.x”按钮和下载进度。
- 启动检查仍可关闭；没有发现新版本时不会下载任何附件。
- 更新前明确显示目标版本、安装包大小、来源、校验方式和数据保留范围，由用户点击确认。
- 只接受 `PascalePaF/wechat-wecom-duokai` 正式 GitHub Release 中名称完全匹配的安装包。
- GitHub 服务端附件摘要、`SHA256SUMS.txt` 和下载文件三方 SHA-256 必须完全一致。
- 从计算最终哈希到启动安装程序期间保持安装包不可写，安装程序启动后还会再次校验自身哈希、版本、
  更新计划、父进程和目标目录标记。
- 程序文件通过同卷暂存、逐文件替换和备份事务更新；中途失败会逆序恢复旧文件。
- 安装版更新后刷新开始菜单、卸载登记和已有桌面快捷方式。
- 绿色版原地更新，不会转成安装版，也不会新增卸载登记或快捷方式。
- 更新结果写入 `data\logs\update.log`；不上传日志或诊断。
- 目标窗口数恢复为微信与企业微信共用的单一 1–10 数字，两个“启动 / 补开”按钮读取同一数值。
- 升级自 V1.0.6 时，优先沿用原微信目标值，若没有则沿用企业微信值；首次保存后删除两个旧字段。

## 安全边界

- 不静默更新：只有用户在确认框点击“是”后才下载和执行安装包。
- 不接受第三方域名、其他仓库、重命名附件、缺少 GitHub SHA-256 的附件或重复校验记录。
- 不覆盖未带本项目专用标记的普通文件夹、源码目录或身份冲突目录。
- 不覆盖 `data`；设置、主题、客户端路径、诊断、更新日志和注册表恢复记录全部保留。
- 更新失败不会降级到执行未校验文件；用户始终可以打开 GitHub Release 手动更新。
- 项目仍未使用付费 Authenticode 证书。请仅使用本 Release 附件并核对 `SHA256SUMS.txt`。

## 文件

- `wechat_duokai-setup-v1.0.7.exe`：安装版、手动安装和一键更新共用的独立安装程序。
- `wechat_duokai-portable-v1.0.7.zip`：绿色免安装版。
- `wechat_duokai-cleanup-v1.0.7.exe`：独立完整清理器。
- `SHA256SUMS.txt`：正式附件与主程序校验值。
- `manifest.spdx.json`：SPDX 2.2 SBOM。
- `kaspersky-scan-v1.0.7.txt`：对正式 GitHub CI 发布原件执行的卡巴斯基扫描日志。
