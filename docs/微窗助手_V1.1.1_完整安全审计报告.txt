微窗助手 V1.1.1 完整安全审计报告
=================================

文档编号：WC-SA-2026-09-20-V111
审计日期：2026-09-20（Asia/Tokyo）
审计对象：V1.1.1 源码、更新检查协议、主程序、安装器、清理器与候选发布目录

一、结论
--------

V1.1.1 修复了 GitHub 未登录 API 每小时 60 次配额耗尽时的更新误报。现场证据明确为 HTTP 403、
X-RateLimit-Remaining=0；同一时刻 GitHub 普通 Release 页面和附件可以访问。没有证据表明本次失败来自
恶意代码、后台上传、DNS 劫持或反病毒软件拦截。

本次修改没有增加遥测、账号读取、聊天读取、远程控制、DLL 注入、客户端文件修改或后台上传。
网络目标仍被固定为本项目 GitHub 仓库；诊断、设置、更新暂存、恢复日志仍位于程序目录 data 下。

二、修复内容
--------

1. 最新版本号优先从 github.com 本项目 releases/latest 的可信 302 跳转取得，不消耗 REST API 配额。
2. 当前已是最新版时不访问 api.github.com。
3. 发现更新后优先取得 GitHub 生成的附件 digest；API 限流/超时/连接失败时，自动转为固定版本
   Release 附件头校验。
4. 降级只接受 HTTPS、精确仓库/标签/附件名、GitHub 最终交付域、正数文件大小和本地大小上限。
5. 只有用户确认后才下载 SHA256SUMS.txt 和 setup；清单必须有且只有一条目标 setup 哈希。
6. API 可用时执行 digest/清单/本机文件三方 SHA-256；API 不可用时执行固定来源/清单/本机文件校验。
7. 下载文件在启动安装器前保持不可写并再次计算哈希；原有标记目录、计划、暂存、备份和回滚保持不变。
8. 真实网络失败显示具体原因；HttpClient 超时不再被当作用户主动取消。

三、威胁边界复核
--------

- 更新地址不能由远端 JSON 任意指定；只接受代码中固定仓库生成的标准 URL。
- 最新版本跳转不能跨域、降级为 HTTP、加入查询参数/片段或插入额外路径。
- 自动重定向后的附件交付域必须属于 GitHub。
- setup 上限 20 MiB，SHA256SUMS.txt 上限 256 KiB；声明大小和实际下载大小必须一致。
- 无论是否取得 API digest，下载后 setup 都必须匹配清单 SHA-256；不匹配文件不会执行。
- 自动更新只覆盖带本项目安装版或绿色版标记的目录，不覆盖源码目录或任意未标记目录。
- 失败覆盖使用逐文件备份逆序回滚，不触碰 data 中的用户设置与恢复证据。

四、自动与现场验证
--------

- 完整 smoke tests：通过。
- 新增 API 403 / X-RateLimit-Remaining=0 回归：通过。
- 非 GitHub跳转、恶意附件 URL、嵌套路径、重复附件、无效 digest：继续拒绝。
- 本机真实配额为 0：成功发现 V1.1.0，setup 761,856 字节，SHA256SUMS.txt 580 字节，
  CanInstallUpdate=True。
- Release 编译、版本一致性、发布哈希、GitHub Actions/SBOM 与 Kaspersky 正式附件扫描：作为发布门禁。

五、剩余限制
--------

1. 项目没有付费 Authenticode 代码签名；Windows 或第三方安全软件可能基于低信誉给出提示。
2. API 不可用时无法取得 GitHub 服务端独立 digest，因此使用固定 HTTPS Release 来源、严格大小和
   SHA256SUMS.txt/下载文件一致作为降级链。仓库账号本身若被完全接管，未签名发布仍无法获得独立信任根。
3. GitHub、网络代理或 HTTPS 检查软件完全不可达时，程序只能显示具体错误并提供浏览器发布页入口。
4. 反病毒零检出只能作为证据，不能证明绝对安全；应同时核对源码、标签、SHA-256、CI 和 SBOM。

六、使用建议
--------

- 只从 https://github.com/PascalePaF/wechat-wecom-duokai/releases 下载。
- 核对 SHA256SUMS.txt，不关闭卡巴斯基，不设置永久白名单。
- V1.0.11 若仍受旧 API 限流影响，可等配额恢复后检查更新，或手动下载 V1.1.1 覆盖升级。
