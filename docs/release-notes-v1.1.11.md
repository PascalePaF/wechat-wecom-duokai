# 微窗助手 V1.1.11

发布日期：2026-10-31

本版将万圣节日间与夜间升级为完整节日外观，而非仅替换配色。

- 双窗口品牌标识增加巫师帽与幽灵变体，应用内标识和活动窗口图标随主题切换。切回普通主题恢复绿蓝品牌标识；程序 EXE 和固定快捷方式不被重写。
- 背景增加月亮、蝙蝠、星芒、蛛网和边缘悬挂幽灵；日间采用暖纸氛围，夜间采用月光紫。
- 卡片使用分层渐变、暖金与紫色边框；客户端图标底框、数量控件和输入框加入节日细节。
- 主按钮增加幽灵图标、渐变和高光，次按钮使用糖果纹饰线，保留危险操作的红色语义。
- 主程序、设置/介绍、安装器、清理器、提示框与路径选择器共享同一套节日视觉。
- 修复路径选择器窄按钮的文字裁切，并检查实际文字宽度与按钮边界。
- 装饰不接收鼠标或键盘焦点，不下载远程素材，不增加动画计时器；普通主题及业务操作保持不变。

提供安装版、绿色版、独立清理器、哈希、更新清单、SPDX SBOM 和扫描证据。安装仍需确认。

没有公共代码签名；扫描未检出不代表绝对安全。旧提交和不可变 Release 不改写。
