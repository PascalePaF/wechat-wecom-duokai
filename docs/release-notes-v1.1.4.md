# 微窗助手 V1.1.4 版本说明

发布日期：2026-09-21

## 恢复 V1.0.10 目标窗口数卡片

V1.1.0 为了统一左右卡片轨道，曾把右侧“目标窗口数”的五段居中结构压缩成四段比例结构。外框虽然
保持对齐，但标题说明被移到底部状态条，计数器与状态条之间产生了过多空白。V1.1.4 按用户提供的截图
和仓库内 V1.0.10 日间/夜间基线，恢复该卡片的原始视觉结构。

- 标题下恢复“微信与企微共用”。
- `− / 数字 / +` 恢复到卡片中部的 76 像素操作区。
- 底部提示恢复为“●  数量会自动保存”，字号恢复为 11。
- 整个内容组使用 V1.0.10 的 `Auto / 18 / 76 / 12 / Auto` 五段结构并垂直居中。
- 左右外框仍保持同顶、同底；应用卡片、全部退出按钮、页脚实时数量和设置入口不变。
- 901×513 最小界面、全屏/超宽等比例缩放、日间/夜间主题和无外层滚动条行为不变。

V1.1.3 的静态更新清单、环境变量代理兼容、TLS 1.2、多重 SHA-256、24 小时缓存、错峰、退避、
事务更新和不可变 Release 安全边界全部保留。
