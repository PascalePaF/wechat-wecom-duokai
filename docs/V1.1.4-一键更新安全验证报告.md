# V1.1.4 一键更新安全验证报告

文档编号：`WD-V114-UPDATE-20260921`

## 1. 变更边界

V1.1.4 只修改主窗口 XAML 中的目标数量卡片、对应 UI 回归断言、版本号和发布资料。以下更新组件未改：

- `ReleaseUpdateChecker`；
- `NetworkProxyPolicy`；
- `UpdateCheckSchedule`；
- `ApplicationUpdateService`；
- 安装器事务更新与回滚协议。

## 2. 保留的验证链

1. `latest/download/update-manifest.json` 仍是免 REST API 配额的主发现路径。
2. 静态清单必须匹配固定仓库、版本标签、规范附件 URL、精确大小和 SHA-256。
3. GitHub API 只提供可选附件 digest 交叉核验；限流或暂时不可用不阻断静态主路径。
4. 用户确认后才下载 `SHA256SUMS.txt` 和 setup。
5. 静态清单、SHA256SUMS 和本机文件必须一致；API digest 可用时也必须一致。
6. 安装版与绿色版继续使用标记目录、同卷暂存、备份和失败回滚，不静默执行。

## 3. 发布门禁

- 本机 Release 全量编译和自动测试；
- 全新 GitHub Windows Server 2022 重建；
- SHA256SUMS 和静态清单逐项复核；
- SPDX 2.2 SBOM 生成与验证；
- 对最终 CI 原件执行 Kaspersky 全目录扫描；
- 草稿 Release 逐项比对 GitHub 服务端大小与 digest 后再发布；
- 正式 Release 启用不可变保护。

结论：本轮 UI 回归修复不改变网络、下载、摘要、执行或回滚边界。
