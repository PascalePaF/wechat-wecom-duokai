微窗助手 V1.0.10 完整安全审计报告
====================================

报告日期：2026-09-19（Asia/Tokyo）
审计对象：PascalePaF/wechat-wecom-duokai V1.0.10 源码、品牌资源、构建脚本和候选发布文件

一、结论摘要
------------

未发现后台上传聊天、账号、联系人、凭据、诊断或本地路径的代码；未发现 DLL 注入、远程线程、客户端
文件修改、键盘记录、屏幕抓取、持久化服务、计划任务、隐藏驱动或任意远程命令执行链。V1.0.10 的新增
代码用于品牌更名、静态 Logo 生成、绿蓝主题资源、旧快捷方式精确迁移和测试，不增加敏感权限或网络端点。

二、品牌资源审计
--------------

1. WeichuangLogo.svg 是可读的本地矢量：两个圆角窗口、四个识别点和一个连接色块。
2. WeichuangLogo.png 是 1024×1024 透明静态位图；favicon.ico 只封装
   16、20、24、32、40、48、64、128、256 像素 PNG 帧。
3. 颜色为原创的同类色体系：绿色 #20B26B、蓝色 #3D8EF7、薄荷色 #62D6C5；没有复制微信或企业微信
   官方商标图形，也不包含脚本、网络引用、宏或可执行载荷。
4. scripts/generate-brand-assets.ps1 只使用 Windows 自带 System.Drawing，在项目内确定性生成 PNG 与 ICO；
   不访问网络、不启动外部下载器、不写项目外目录。

三、更名与升级安全
----------------

面向用户名称从“开开助手”改为“微窗助手”，但 EXE 名、默认安装目录、卸载注册表键、目录标记、配置路径
和更新协议保持不变。覆盖安装不会创建第二套程序或丢失 data。

安装完成后仅删除三代品牌下的精确已知 .lnk 文件；旧开始菜单目录只有为空时才删除。代码不递归清理旧
品牌目录，不会删除未知文件。卸载清理仍需精确计划路径、专用标记与目录结构同时通过校验。

四、客户端与注册表边界
--------------------

- 客户端路径必须符合微信/企业微信文件名、产品元数据和有效腾讯 Authenticode 签名。
- 实例统计只读取当前 Windows 会话中匹配同一官方路径的进程关系。
- 不结束微信或企业微信；覆盖安装只处理所选安装目录中的助手进程。
- 企业微信 multi_instances 修改在短期会话前写入 data/recovery 落盘事务；正常/异常结束后仅在当前值
  仍等于助手临时状态时恢复。第三方已经写入新值时保留新值，避免用旧快照覆盖。
- 已知互斥锁与 lock.ini 处理均受名称和精确路径白名单限制，不扩展为任意句柄关闭。

五、网络与更新边界
----------------

启动检查（用户可关闭）和手动检查只读取 api.github.com 上本项目正式 Release。只有用户确认“一键更新”
后才下载同一 Release 的 SHA256SUMS.txt 与精确版本 setup。程序不上传本地内容。

执行下载文件前要求 GitHub asset digest、SHA256SUMS 和本机文件 SHA-256 三方一致；安装器再验证更新计划、
父进程、时效、目标目录身份和文件哈希。替换采用同卷暂存、备份与回滚，data 永不进入替换列表。

六、数据与删除边界
----------------

设置、主题、诊断、恢复、日志和更新证据位于程序目录 data。系统集成只包括开始菜单、可选桌面快捷方式
和当前用户卸载登记。完整清理对安装目录、绿色包、发布目录和可选源码分别验证专用标记、精确结构、
解析后路径与链接属性；拒绝磁盘根、系统目录、未标记目录和目录联接。

七、发布验证
------------

正式发布前执行：Release 重建、全体自动测试、14 场景 UI 回归、双次确定性组包、SHA-256 复核、全新
GitHub-hosted Windows 重建、SPDX 2.2 SBOM 生成/验证，以及 Kaspersky 对最终 CI 工件原件扫描。扫描原始
日志随 Release 公开。未检出是证据而非绝对保证，用户仍应核对来源、哈希、标签和源码。

八、已知限制
------------

项目未购买公共信任代码签名证书，Windows 或安全软件可能因“未知发布者”、低信誉或启发式模型提示。
这些提示不应盲目忽略，也不应通过关闭安全软件解决；应隔离并对照正式 Release 哈希、CI、SBOM、扫描
日志和源码复核。腾讯未公开承诺第三方多开机制长期稳定，客户端策略变化时工具可能无法补开。
