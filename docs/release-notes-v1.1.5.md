# 微窗助手 V1.1.5 版本说明

发布日期：2026-09-22

## 开机自动启动

设置页新增“开机后自动启动微窗助手”，使用当前 Windows 用户的标准 `Run` 启动项，不申请管理员权限。
可继续选择“自动启动时最小化窗口”。这两个选项只控制助手自身，不会自动打开微信或企业微信。

- 启动命令固定为带正式身份标记目录中的 `wechat_duokai.exe --autostart`。
- 绿色版整体移动后，下次正常启动会把本程序拥有的旧路径修复为新路径。
- 同名启动项如果不符合本项目精确命令格式，会被视为外部冲突：不覆盖、不删除，并向用户提示。
- 开机任务重复启动、但助手已经运行时，第二个自动启动进程会静默退出，不弹出干扰提示。
- 完全卸载只在启动项解析出的 EXE 与已验证安装目录或绿色目录完全一致时删除该项。

## 更可靠的检查与自动更新准备

设置页新增“发现后自动下载并校验（安装前确认）”。它不是静默安装：程序只在后台准备来自本项目
GitHub Release 的正式 setup，并完成与手动一键更新相同的多重 SHA-256 验证；运行安装程序前仍要
用户明确确认。

- 检查状态新增“上次成功 / 下次检查”本地计划说明。
- 完整验证过的同版本更新包可以复用，避免重复下载。
- 复用前重新核对静态清单或 GitHub 摘要、`SHA256SUMS.txt`、精确大小和本机 setup 哈希。
- 任一项不一致时，只清除该版本两个已知缓存文件，然后从可信 Release 重新下载。
- 启动独立安装程序前再次计算 setup 的 SHA-256，防止下载完成后被替换。
- 静态 `update-manifest.json` 仍是免 API 配额主路径；GitHub API 仅作可选摘要交叉核验。
- 24 小时成功缓存、30–300 秒错峰、1/6/24 小时失败退避、`Retry-After` 和环境代理兼容全部保留。

## 设置页与验证

设置页在 901×513 最小尺寸重新压缩信息层级，开机启动、自动下载、检查计划和诊断按钮在日间与夜间
主题中都完整可见，不增加滚动条。诊断报告会列出四项开关状态，但不会记录启动命令、账号、聊天、
代理凭据或访问令牌。

本轮新增启动项创建/移动修复/外部冲突/精确清理、自动启动参数、设置持久化、检查计划、可信缓存复用
和缓存篡改拒绝测试，并继续执行 14 场景 UI 回归、全新 Windows CI、哈希复核与 SPDX 2.2 SBOM。
