# V1.1.0 — 分端全部退出与界面对齐

V1.1.0 在不增加新面板的前提下，为微信和企业微信分别加入“全部退出”，并继续收紧进程边界。
同时按用户提供的截图重新整理左右主卡片、页脚实时数量和标题区，让最小界面更简洁、对齐更准确。

## 本版变化

- 微信、企业微信各自拥有一个紧凑的“全部退出”按钮；不会因为退出微信而影响企业微信，反之亦然。
- 点击后显示数量、未保存内容风险和“不注销账号”说明，默认选择为“否”。
- 只选择当前 Windows 会话、完整路径与已经验证的官方客户端完全一致的进程；操作前再次读取会话和路径。
- 先请求客户端正常关闭并等待 2 秒，只有残留的匹配进程才会被结束；权限不足或身份变化时跳过并报告。
- 左右主卡片改为相同的四行比例，外框、标题、操作区与状态区在最小窗口和全屏下保持对齐。
- 左下角微信/企微数量使用绿/蓝粗体数字与独立留白，同时保留完整辅助功能文本。
- 删除左上角重复副标题，数量卡片说明压缩为“微信与企微共用 · 自动保存”。
- 增加退出边界、按钮、页脚、布局自动测试，并更新 14 场景 UI 回归、安全审计和使用说明。

## 安全边界

- 不注入 DLL、不写客户端内存、不修改或替换微信/企业微信文件。
- 不会后台自动关闭客户端；退出必须由用户在对应卡片点击并确认。
- 不处理其他登录会话、其他安装路径、路径无法读取或实时身份无法确认的同名进程。
- 网络仍只用于固定 GitHub 仓库的版本检查和经用户确认、三方 SHA-256 校验的一键更新。
- 项目未使用 Authenticode 代码签名；请只从正式 Release 下载并核对哈希、CI、SBOM 与扫描日志。
