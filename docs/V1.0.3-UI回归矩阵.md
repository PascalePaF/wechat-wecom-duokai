# V1.0.3 UI 回归矩阵

## 自动布局断言

| 窗口 | 场景 | 预期 |
| --- | --- | --- |
| 主窗口 | 680×520 | 数量卡片在第二行，主内容可纵向滚动，版本胶囊隐藏 |
| 主窗口 | 790×600 | 断点进入宽布局，数量卡片回到最右侧 |
| 主窗口 | 960×640 | 默认布局完整、客户端路径自动省略 |
| 主窗口 | 1280×800 | 卡片比例稳定、状态区不会抢占操作按钮 |
| 主窗口 | 1920×1080 | 无最大尺寸限制，可用于最大化/全屏工作区 |
| 全部窗口 | 原生标题栏 | 可拖动、最小化、最大化、关闭和边缘缩放 |
| 全部窗口 | Light / Dark | 动态资源完整，文字、边框、阴影和状态色可辨识 |
| 安装器 | 安装前 / 完成态 | 安装完成后必须显示“确认并启动”，不会自动启动 |
| 清理器 | 保留源码 / 删除源码 | 危险选项默认未选中，删除源码需要额外确认 |

## 发布前人工检查

- [ ] 100%、125%、150%、175%、200% DPI 下标题、按钮和输入框没有裁切。
- [ ] 从不同缩放比例的两个显示器之间拖动，WPF 按 Per-Monitor V2 重新排版。
- [ ] 680×520 下滚动到数量卡片，页脚“诊断”和“发布版本”保持可见。
- [ ] 默认宽度下微信/企业微信图标位于左侧，目标数量位于最右侧。
- [ ] 最大化与还原后断点、滚动位置和主题正常。
- [ ] 日间主题阴影自然，没有黑色硬边；夜间主题卡片层级清楚，不出现发光边。
- [ ] 超长中文客户端路径只在界面省略，悬停仍可查看完整路径。
- [ ] 键盘 Tab 顺序覆盖主题、路径选择、启动、数量、诊断和 Release。
- [ ] Windows 高对比度、屏幕阅读器名称和 200% 文本缩放至少完成一次人工检查。
