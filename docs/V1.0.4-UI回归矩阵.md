# V1.0.4 UI 回归矩阵

## 自动布局断言

| 窗口 | 场景 | 预期 |
| --- | --- | --- |
| 主窗口 | 901×513 | 精确最低尺寸；全部主操作可见；不存在包裹工作区的滚动容器 |
| 主窗口 | 任意支持尺寸 | 微信/企业微信在左侧，目标数量卡片始终位于最右侧，不发生上下堆叠 |
| 主窗口 | 放大/还原 | `ScaleX` 与 `ScaleY` 相同且不小于 1，字体、图标、按钮、圆角、阴影共同缩放 |
| 主窗口 | 1280×720 | 比例约 1.40×；逻辑画布经变换后覆盖全部视口 |
| 主窗口 | 1920×1080 | 比例约 2.10×；内容不挤在顶部，无固定最大尺寸 |
| 主窗口 | 3440×1392 | 比例约 2.71×；左右卡片按比例吸收超宽空间，不留大块空白 |
| 全部窗口 | 原生标题栏 | 可拖动、最小化、最大化、关闭和边缘缩放 |
| 全部窗口 | Light / Dark | 动态资源完整，文字、边框、自然阴影和状态色可辨识 |
| 安装器 | 安装前 / 完成态 | 安装完成后必须显示“确认并启动”，不会自动启动 |
| 清理器 | 保留源码 / 删除源码 | 危险选项默认未选中，删除源码需要额外确认 |

## 发布前人工检查

- [ ] 901×513 下不出现外层纵向或横向滚动条，第二个应用卡片和页脚没有裁切。
- [ ] 1280×720、1920×1080 和 3440×1392 下文字、图标、按钮和输入框同步变大。
- [ ] 超宽屏左右卡片铺满主工作区，目标数量不变成贴在顶部的微型卡片。
- [ ] 最大化、还原、连续拖动边缘时没有闪烁、错位、空白条或非等比变形。
- [ ] 日间主题阴影柔和，没有黑色硬边；夜间主题层级清楚，不出现发光边。
- [ ] 100%、125%、150%、175%、200% DPI 下标题、按钮和输入框没有裁切。
- [ ] 从不同缩放比例的两个显示器间拖动，Per-Monitor V2 正确重新合成。
- [ ] 超长中文客户端路径只在界面省略，悬停仍可查看完整路径。
- [ ] 键盘 Tab 顺序覆盖主题、路径选择、启动、数量、诊断和 Release。
- [ ] Windows 高对比度、屏幕阅读器名称和 200% 文本缩放至少完成一次人工检查。

自动截图用于发现布局回归，不能替代真实显示器上的 ClearType、显卡合成、跨 DPI 拖动和辅助技术检查。
