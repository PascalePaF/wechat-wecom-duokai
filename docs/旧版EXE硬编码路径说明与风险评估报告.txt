一、结论摘要

1. “硬编码本机微信路径”是指：旧版 duokai.exe 内部直接写入了一个固定的绝对路径，
   而不是在每台电脑上自动查找微信安装位置，也不是让用户自行选择位置。

2. 在本次检查的旧版 duokai.exe 中发现的固定路径为：

   D:\中文安装地址\微信\Weixin\Weixin.exe

3. 硬编码本身不等于病毒或后门，但会造成明显的兼容性和可追溯性问题：
   - 只要微信没有安装在这个完全相同的位置，功能就可能失效；
   - 微信移动目录或升级后更换位置，旧版程序可能无法启动微信；
   - 该 EXE 与当前 GitHub 上可见源码并非完全一致，外部人员无法仅凭仓库源码
     重新构建出内容相同的二进制文件，因此需要对它的来源保持谨慎。

4. 静态代码检查和卡巴斯基扫描均未发现后门或恶意软件证据。但任何单次静态检查、
   反病毒扫描都不能在数学意义上证明“绝对安全”，因此本报告采用“未发现风险证据”
   的表述，而不作百分之百安全承诺。

三、“硬编码”具体是什么意思

正常的跨电脑程序一般会采用以下一种或多种方式查找微信：

1. 读取微信安装程序写入的 Windows 注册表；
2. 读取当前正在运行的微信进程路径；
3. 检查官方常见安装目录；
4. 自动检测失败后，让用户通过文件选择器指定 Weixin.exe。

旧版 EXE 则把“D:\中文安装地址\微信\Weixin\Weixin.exe”这一整段地址作为固定文字
编译进程序。编译完成后，普通用户无法在界面中更改它。可以把它理解为：程序不是在问
“微信安装在哪里”，而是始终认定“微信就在这个地址”。

该路径恰好与本机当前安装位置一致，因此旧版程序在本机可以运行；换到另一台电脑、
换一个磁盘或更改文件夹名称后，就很可能失效。

四、是否属于后门

本次反编译和静态检查未发现以下后门常见行为：

- 未发现后台上传账号、聊天记录或本地文件的网络通信；
- 未发现读取微信聊天数据库、登录凭据或消息内容；
- 未发现开机自启动、计划任务、隐藏服务等持久化行为；
- 未发现 DLL 注入、远程线程、进程替换等注入行为；
- 未发现秘密下载并执行其他程序；
- 未发现结束或破坏微信、企业微信进程的逻辑。

旧版程序中可见的外部网络地址仅用于用户主动点击后打开项目作者网页；没有发现它在后台
自动连接该地址。因此，目前没有证据表明该固定路径是为了后门用途。

六、风险分级

恶意代码风险：低（静态检查与卡巴斯基均未发现恶意证据）
兼容性风险：高（固定绝对路径无法适配其他安装位置）
来源可追溯风险：中（旧版 EXE 与公开仓库源码存在差异，且无数字签名）
隐私泄露风险：低（未发现读取或上传聊天、账号、凭据的代码）

七、建议与 V1.0.1 当前处理方式

建议取消固定绝对路径，改为分层自动检测；检测失败时再提供用户选择功能。V1.0.1 当前
已经采用以下方式：

1. 优先使用可信的 Windows 注册表安装信息；
2. 其次识别已运行的微信或企业微信进程位置；
3. 再检查官方常见安装目录；
4. 不修改微信和企业微信的程序文件；
5. 不再依赖上述“D:\中文安装地址\……”固定路径。

后续可继续增加“手动选择客户端 EXE 并保存”的兜底入口。这样既能照顾非标准安装目录，
也能避免重新引入只适用于某一台电脑的固定路径。

八、最终意见

旧版 EXE 中的固定本机路径主要是工程质量和可移植性问题，不是后门的直接证据。
考虑到旧版文件无数字签名、与公开源码不完全一致，建议日常使用可由当前仓库源码重新构建、
带 SHA-256 校验值和卡巴斯基扫描日志的 V1.0.1 或后续版本，并保留源码与发布标签以便复核。
