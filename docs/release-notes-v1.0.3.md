# V1.0.3 — 安全覆盖、官方客户端验证与响应式界面

V1.0.3 重点完善升级安装、官方客户端兼容、窗口缩放与本地排障。安装器、绿色版和独立清理器
全部由同一标签源码构建，发布时同时提供 SHA-256、安全审计和 Kaspersky 原始扫描日志。

## 本版重点

- 覆盖安装前只检测所选安装目录中的助手。用户可选择正常关闭；5 秒仍未退出时，再单独决定是否
  强制关闭。默认不强制，也不会结束微信、企业微信或其他目录中的助手。
- 支持手动选择任意目录中的官方微信/企业微信程序。文件名、腾讯产品信息和有效 Tencent
  Authenticode 签名必须同时通过，重命名的陌生 EXE 会被拒绝。
- 微信 3.x/4.x 两代入口名与企业微信现行入口名不使用补丁版本白名单；本机已验证微信 4.1.15.6、
  企业微信 5.0.11.6018 和中文自定义路径。
- 主界面支持 680×520 最小尺寸、自由缩放、最大化、紧凑/宽屏响应式布局、Per-Monitor V2 DPI，
  同时保留日间与夜间主题。
- 页脚新增低干扰“诊断”按钮，只在程序目录的 `diagnostics` 文件夹写本地报告，不自动上传。
- 启动时只向本项目 GitHub API 读取最新 Release 标签。发现更新后仅提供浏览器入口；客户端不会
  下载、替换或执行更新文件。
- setup 与 cleanup 已拆成不同程序集、不同产品身份和不同二进制；安装器嵌入真正的独立清理器。
- 进程枚举、父子关系、启动和等待抽象为可测试环境；回归测试覆盖增量补开、安装安全、独立身份、
  自定义路径、更新边界、诊断目录、窗口尺寸与已知单实例锁。

## 下载选择

- `wechat_duokai-setup-v1.0.3.exe`：推荐的当前用户安装版，可用文件夹选择器指定安装位置。
- `wechat_duokai-portable-v1.0.3.zip`：绿色免安装版，解压完整目录后运行 `wechat_duokai.exe`。
- `wechat_duokai-cleanup-v1.0.3.exe`：独立清理器，可保留源码清理程序，也可在额外确认后清理源码。
- `SHA256SUMS.txt`：核验安装包、清理器、绿色 ZIP、主程序和 Core。

## 发布验证与安全说明

- Release 完整重编译与 17 项自动测试通过；连续两次构建的五项发布哈希一致。
- Kaspersky 21.26、病毒库 2026-09-13 12:03:00（full）：最终发布目录处理 36 个对象，检测 0、
  可疑 0、跳过 0、损坏 0、错误 0。原始日志作为本 Release 附件提供。
- 静态审计未发现聊天/账号读取、隐私上传、隐藏下载、代码注入、驱动、服务、计划任务或开机自启。
- 本项目不是腾讯官方产品；多开机制可能随客户端更新变化，请遵守客户端许可和组织规定。
- 本版尚未配置公共信任的代码签名，因此 Windows 仍可能显示“未知发布者”或信誉告警。未签名不等于
  恶意，零检出也不是绝对安全保证；请从本 Release 下载、核对 SHA-256，并保持安全软件开启。

## 技术决定

本版继续使用 WPF/.NET Framework 4.8，不迁移 WinUI 3、Tauri 或 Python；WiX/MSI 暂列为企业部署
触发项。代码签名优先申请 SignPath Foundation，未获接受时再评估 Microsoft Artifact Signing 或
传统 OV 证书。完整依据见随 Release 提供的技术决策与兼容性报告。
