微窗助手 V1.1.5 完整安全审计报告
=================================

文档编号：WD-V115-SECURITY-20260922
审计日期：2026-09-22
项目地址：https://github.com/PascalePaF/wechat-wecom-duokai

一、执行结论
------------

未发现 V1.1.5 存在后台上传隐私、聊天/账号/凭据采集、广告遥测、远程控制、静默安装、DLL 注入、
客户端文件修改或隐藏载荷。新增开机自动启动必须由用户在设置中主动开启；新增自动下载只准备并校验
本项目正式更新包，运行安装程序前仍必须由用户确认。

二、开机自动启动边界
--------------------

1. 仅使用当前用户 HKCU 标准 Run 启动项，不安装服务、驱动或计划任务，不请求管理员权限。
2. 命令固定为完整引号路径的 wechat_duokai.exe 加唯一 --autostart 参数。
3. 开启前要求当前目录具有本项目安装版或绿色版专用身份标记，源码和普通开发输出目录不能注册。
4. 绿色版移动后只修复能够证明属于本项目的旧路径。
5. 同名值不符合精确命令格式时视为外部冲突：不覆盖、不删除。
6. 清理器只在解析路径与已验证安装/绿色目标完全相等时删除启动项。
7. 自动启动只运行助手；是否最小化可单独选择，不自动启动微信或企业微信。

三、更新与自动下载边界
----------------------

1. 固定 GitHub 仓库的静态 update-manifest.json 是免 API 配额主路径；API 只作可选摘要核验。
2. 只接受规范 Release URL、正式 setup 和 SHA256SUMS.txt，并限制名称、大小、域名及重定向目标。
3. 自动下载默认关闭。开启后不静默执行，用户仍需在安装确认框中明确同意。
4. 本地缓存只有在可信清单摘要、SHA256SUMS 唯一记录、精确大小与 setup 实际 SHA-256 全部一致时复用。
5. 缓存损坏时只删除该版本两个精确已知文件，不扩大到 data、安装目录或其他版本。
6. setup 启动前再次读取和计算 SHA-256；更新计划使用写穿保存、父进程身份和事务 ID。
7. 安装器继续执行专用标记、路径、版本、哈希、同卷暂存、逐文件备份与失败回滚。

四、其他敏感能力复核
--------------------

- 微信/企业微信自动定位和自定义路径继续验证官方文件名、产品信息与腾讯 Authenticode 签名。
- 多开只处理已知单实例锁，不注入 DLL、不写进程内存、不修改客户端文件。
- 企业微信 multi_instances 修改前仍写穿保存恢复事务；异常恢复只在临时状态仍归助手所有时执行。
- “全部退出”仍需确认，只处理当前会话中与已验证精确客户端路径匹配的进程。
- 配置、更新状态、下载、诊断、恢复和日志仍位于应用目录 data。
- 诊断新增四项布尔开关状态，不记录启动命令、账号、聊天、联系人、代理凭据或访问令牌。
- 启用检查时只向 GitHub 发出普通 HTTPS 请求；不上传设置、路径、诊断、恢复日志或使用数据。

五、验证与发布门禁
------------------

新增自动测试覆盖启动项创建、移动修复、外部冲突、精确卸载、自动启动参数、偏好持久化、检查计划、
可信缓存复用和缓存内容篡改拒绝。既有客户端签名、多开、断电恢复、精确退出、安装事务、更新回滚、
代理、TLS、UI 缩放和独立编译身份测试继续执行。

正式发布继续要求：本机完整构建与测试；全新 GitHub Windows Server 2022 重建；SHA256SUMS 和
update-manifest 逐项复核；SPDX 2.2 SBOM 生成与验证；最终 CI 原件卡巴斯基扫描；草稿 Release 服务端
大小与摘要核对；最后发布不可变 Release。具体扫描结果以同版本 Release 的原始日志为准。

六、剩余风险与使用建议
----------------------

项目未使用公共信任的 Authenticode 商业签名，SmartScreen 或第三方启发式引擎可能因低信誉、进程锁、
企业微信注册表临时状态、开机启动项或自更新行为提示风险。提示不等于确认恶意，反病毒未检出也不是
绝对安全证明。应只从正式 GitHub Release 下载，核对标签、SHA256SUMS、CI、SBOM、源码与同版本扫描日志；
遇到明确恶意项时先隔离核查，不要关闭防护或盲目建立永久白名单。

最终判断：V1.1.5 新增启动与更新体验功能，但没有放宽网络来源、摘要验证、执行授权、注册表归属、
文件删除或进程控制边界；未发现后门或恶意数据链。
