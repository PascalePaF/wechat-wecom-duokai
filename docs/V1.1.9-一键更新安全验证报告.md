# V1.1.9 更新与安装安全验证

更新来源、固定附件名、HTTPS、大小限制、SHA256SUMS 交叉验证、启动前持锁重算哈希、确认式安装和失败回滚保持不变。

本版增加季节主题的完整交接：允许 `light`、`dark`、`halloween` 三种规范参数；主程序传递当前主题，安装器和清理器复用同一解析实现，未知参数不能拼入执行命令。主题偏好仍由安装/升级事务保留在程序自己的 `data` 目录。

更新状态读取限量 64 KiB，更新交接计划限量 16 KiB。设置备份也有相同限量边界；超大、锁定或重定向文件按既有失败/恢复流程处理，不执行未验证更新。

验证包括主题参数往返、四种偏好重读、写入失败保留旧偏好、网络停滞与用户取消、摘要不符拒绝、安装失败回滚、设置保留、完整卸载。

正式发布使用同一次成功 Windows CI 的原始二进制与清单，发布前核对所有附件摘要；公开后再检查更新发现与下载验证链路，不自动执行安装器。
