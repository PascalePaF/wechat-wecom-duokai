# 微窗助手 V1.1.7 版本说明

发布日期：2026-10-22

本版将 QQ 加入主界面，并把原先残留的系统通用提示框、文件选择框和文件夹选择框统一到现有日间/夜间主题。

## 功能变化

- 主界面从上到下为 QQ、微信、企业微信；三端共用一个自动保存的目标数量，分别提供“启动 / 补开”和经确认的“全部退出”。左下角分别显示三个客户端的根实例数。
- 自动定位或手动选择 QQ 时，仅接受文件名为 `QQ.exe`、产品信息匹配且具有有效腾讯 Authenticode 签名的官方客户端。进程统计仍限定当前 Windows 会话和精确程序路径。
- QQ 使用官方程序直接启动，不调用微信/企微的句柄解锁，也不修改 QQ 注册表或二进制。本机腾讯签名 QQ `9.9.35.52892` 从一个根实例启动出第二个根实例；未验证多账号登录或所有 QQ 版本，不能保证目标 1–10 全部可达。
- 安装、升级、清理、错误及退出确认改用统一 WPF 主题弹窗；官方客户端与安装目录选择器也使用同一套颜色、圆角、按钮和字体，支持日夜主题。原生 Windows 标题栏仍保留，以保证窗口可移动和系统行为正常。

## 安全与兼容边界

- 不注入 DLL、不写客户端内存、不修改或替换 QQ、微信、企业微信文件，也不读取聊天、账号、联系人或凭据。
- “全部退出”仅在用户点击并确认后执行，仍只作用于当前会话中与已验证程序完整路径一致的进程。
- QQ 的官方直启行为可能随腾讯新版客户端、账号或安全策略变化；如果启动后根实例数量未增加，助手会显示实际数量，而不会使用注入或补丁绕过限制。
- 程序本身仍未购买受公共信任的 Windows 代码签名。请通过正式 Release、SHA-256、源码和同版本扫描日志核验，不要盲目忽略安全软件明确告警。

自动化测试涵盖三卡片布局、QQ 直启与假冒程序拒绝、主题弹窗/选择器、安装与清理流程；视觉截图矩阵见 `docs/V1.1.7-UI回归矩阵.md`。自动化进程模拟不等同于真实账号的多开兼容测试。
