# V1.1.7 全项目自查报告

文档编号：`WD-V117-AUDIT-20261022`

## 改动边界

| 模块 | 本版处理 | 关键保护 |
| --- | --- | --- |
| 客户端定位 | 加入 QQ 注册表、运行进程和常见目录候选 | 每个候选仍通过文件名、产品信息和腾讯签名校验 |
| 实例管理 | QQ 直接启动、按当前会话/完整路径/根进程计数 | QQ 不经过微信/企微单实例句柄解锁，不写 QQ 注册表 |
| 主界面 | QQ/微信/企微三卡片、三行计数 | 共用 1–10 数字；主窗口最小仍为 901×513，无外层滚动条 |
| 主题界面 | 信息/确认、程序及目录选择器改为 WPF 共用组件 | 日夜主题共用资源；路径被选择后还须走后端验证 |
| 安装与清理 | 清理工作进程继承主题；不再依赖 WinForms | 清理范围和二次确认保留；更新仍须显式确认 |

## 自动验证

本机 Release 构建和完整 smoke 测试覆盖 QQ 根实例直启、拒绝伪装为 `QQ.exe` 的测试程序、三卡片最小/最大布局、三端独立计数、主题弹窗与选择器、现有安装/升级/清理/更新/企业微信注册表恢复边界。另生成 23 场景日夜 UI 截图进行视觉复核。

真实客户端验证仅限本机腾讯签名 QQ `9.9.35.52892`：已有一个根实例时，再执行一次官方 `QQ.exe` 后观察到两个根实例，随后请求关闭本次新增的实例。未验证账号登录、重启后的稳定性或 QQ 所有版本；微信和企业微信本版没有扩大既有兼容承诺。

## 保留风险

- 未签名的助手发布文件仍可能触发信誉或启发式提示，扫描未检出不是绝对安全证明。
- 腾讯未来调整官方 QQ 的启动模型后，直启可能只唤醒旧窗口；本项目不会转向注入、补丁或未经确认的账号数据访问。
- 自绘选择器尚需在更多 DPI、无权限磁盘和键盘辅助技术环境手工验证；OS 标题栏仍由 Windows 呈现。
- 诊断报告含本地程序路径，用户分享前应自行脱敏。项目不自动上传诊断、聊天或账号内容。
