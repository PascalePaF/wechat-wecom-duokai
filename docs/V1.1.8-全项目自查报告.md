## 历史隐私资料

当前默认分支中的原始本机路径改为占位符，界面公开样例统一使用演示数据。旧界面样例从默认分支退出，历史报告仍保留对应测试说明。

旧 Git 提交、标签、已发布的原版安装包可能仍有低敏感度目录名称。完整清除需要协调历史重写、标签和旧附件处理，会改变提交身份或已有附件摘要；本版不执行这种不可逆操作，也不声称历史信息已被抹除。

## 验证限制

模拟进程和接口测试不等于真实账号兼容性测试。未通过真实客户端实测的版本不承诺可达到任意目标窗口数。无公共代码签名，杀毒扫描结果以本版正式原件的扫描附件为准。
