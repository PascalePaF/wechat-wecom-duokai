微窗助手 V1.1.6 完整安全审计报告
=================================

文档编号：WD-V116-SECURITY-20260923
审计日期：2026-09-23
项目地址：https://github.com/PascalePaF/wechat-wecom-duokai

一、本版新增能力与数据流
------------------------

本版未新增服务器、账号体系、遥测或上传接口。自动更新检查仍只读取本项目 GitHub Release 元数据；
可选自动下载仍只写入助手目录下 data\updates，并在用户确认后执行经过 SHA-256 校验的正式安装包。
开机启动仍为当前用户 Run 注册表项，不安装服务、驱动或计划任务。

二、敏感操作复核
----------------

1. 启动项只在路径与当前副本或其本地记载的旧路径相符时自动修改；不同副本默认不互相删除或覆盖。
   用户主动切换时，执行前再次核对所确认的原值，避免覆盖已变化的配置。
2. 第二次启动只向当前 Windows 会话的已运行助手发送唤回信号，不获取微信账号、聊天或联系人。
3. 设置文件的新内容先写穿暂存，再替换旧文件；旧内容保留在同一 data 目录的备份中。
4. 普通安装只接受空目录、有效旧安装或带本项目专用中断标记的目录。有效载荷先完整暂存并核验版本，
   捕获异常后恢复已替换文件。中断标记存在时主程序拒绝运行，要求重新安装。
5. 微信和企业微信客户端的文件名、产品信息及腾讯数字签名校验、精确进程范围、企业微信注册表恢复日志
   等原有保护继续保留；本版不注入 DLL、不修改客户端文件。

三、验证与未消除风险
--------------------

本机自动测试包含故障注入、双副本启动项冲突、设置备份、持续运行更新调度和窗口唤回。
CI、SHA256SUMS、SBOM 和卡巴斯基扫描以最终同版本发布附件和原始日志为准。

项目没有公共信任的 Windows Authenticode 商业签名，安全软件仍可能因低信誉、进程锁或安装行为给出启发式
提示。未检出不等于绝对安全；若出现明确恶意项，应先隔离调查，不应盲目关闭防护或永久加入白名单。
断电中断安装后需要用户重新运行正式安装包，不会在后台自动覆盖或清理。

结论：V1.1.6 主要缩小误改启动项、设置丢失和半安装可运行的风险；源码检查未发现新增的隐私上传链。
