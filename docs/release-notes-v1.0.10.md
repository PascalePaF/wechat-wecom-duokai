# V1.0.10 — “微窗助手”与微信绿 / 企微蓝品牌体系

V1.0.10 重新完成产品命名和视觉品牌。面向用户的正式名称改为“微窗助手”：名称简短、容易输入，
“微”对应微信与企业微信，“窗”对应窗口数量管理。内部 EXE 名、安装目录、卸载登记键、数据标记和
更新协议保持不变，因此可以从 V1.0.9 原地覆盖升级。

## 本版变化

- 正式名称改为“微窗助手”，同步覆盖主窗口、安装器、清理器、文件属性、诊断报告和系统集成项。
- Logo 改为原创的双窗口连接图形，采用微信同类绿色 `#20B26B`、企微同类蓝色 `#3D8EF7` 和连接薄荷色
  `#62D6C5`；不复制官方商标图形。
- 提供可维护 SVG、1024 像素透明 PNG、文档图和包含 16/20/24/32/40/48/64/128/256 像素帧的 Windows ICO。
- 日间界面从偏黄的米金底色改为更清爽的浅灰绿背景，主操作改为深微信绿，信息状态使用企微蓝。
- 夜间界面改为冷静的深绿蓝灰底色；主绿、状态蓝、图标底色和选择色都经过压暗，避免高亮与高饱和刺眼。
- 覆盖安装与一键更新会迁移 V1.0.9 的“开开助手”快捷方式，以及更早版本的旧长名称快捷方式；只删除
  精确已知链接，旧开始菜单目录包含未知文件时绝不递归删除。
- UI 回归继续覆盖主界面、设置、软件介绍、安装器、安装完成态、清理器、双主题、全高清和超宽屏共 14 个场景。
- 多开、按缺口补开、腾讯签名校验、企业微信注册表恢复保护、程序目录数据边界和三方 SHA-256 更新链不变。

## 安全边界

- 不注入 DLL，不修改客户端文件，不读取聊天、账号、联系人或凭据。
- 新 Logo 与主题是本地静态资源，不增加网络端点、权限、进程操作或注册表范围。
- 一键更新仍只接受本项目 GitHub Release，必须通过 GitHub digest、`SHA256SUMS.txt` 和下载文件三方一致校验。
- 项目未购买代码签名证书；请只从正式 Release 下载，核对 SHA-256，并保持安全软件开启。
