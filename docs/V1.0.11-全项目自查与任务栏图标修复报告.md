# V1.0.11 全项目自查与任务栏图标修复报告

审查对象：`PascalePaF/wechat-wecom-duokai` V1.0.11  
审查日期：2026-09-19（Asia/Tokyo）  
范围：主程序、核心库、安装器、清理器、一键更新、构建脚本、GitHub Actions、资源、文档与测试。

## 1. 结论

本轮找到的用户可见问题为：V1.0.10 的三个 EXE 其实已经嵌入新的绿蓝 Logo，但 WPF 窗口没有
显式设置 `Window.Icon`，进程没有稳定 AppUserModelID，快捷方式也没有对应身份，覆盖同一路径后还没有通知 Explorer 废弃旧图标缓存。
这四点叠加会使标题栏、任务栏或历史快捷方式看起来没有跟上 Logo 更名。

V1.0.11 已同时修复这三层，并加入可重复自动验证。对其余代码执行安全与稳定性自查后，未发现
后台上传隐私、恶意持久化、远程控制、客户端文件篡改或任意路径删除代码。

## 2. 任务栏图标根因与修复

| 层级 | V1.0.10 状态 | V1.0.11 修复 |
| --- | --- | --- |
| PE/EXE 图标 | app/setup/cleanup 均已嵌入新 ICO | 保持，并用像素色相自动测试锁定绿蓝 Logo |
| WPF 窗口 | 未显式设置 `Icon` | 三个窗口绑定同一 ICO Resource |
| 任务栏分组 | 依赖 Windows 默认判断 | 主程序、setup、cleanup 分别设置稳定 AppUserModelID |
| Explorer 缓存 | 覆盖同路径后不刷新 | 安装、更新、运行、清理后发送精确项目与关联刷新通知 |
| 快捷方式 | 图标目标正确，但没有显式 Shell 身份 | 通过 `IPropertyStore` 写入与目标进程相同的 AppUserModelID，保存后刷新 Shell |

修复不会删除 `%LOCALAPPDATA%\IconCache*`，不重启 Explorer，不批量修改用户固定项。这避免了为一个应用破坏
全局桌面状态。已固定的历史任务栏项如被 Windows 作为独立旧项保留，需取消固定后从新快捷方式重新固定。

## 4. 安全面自查

### 网络

- 仅有的客户端网络功能是读取 `api.github.com` 上固定仓库的正式 Release，以及在用户明确确认后下载该 Release 的 setup 与校验文件。
- 未发现上传请求、遥测、广告 SDK、隐藏域名、Socket、WebSocket、FTP 或动态代码下载。

### 隐私与客户端访问

- 未读取微信/企业微信聊天库、账号、Cookie、联系人、凭据、剪贴板、摄像头、麦克风或屏幕。
- 客户端路径必须同时符合文件名、产品元数据和有效腾讯 Authenticode 签名。

### 进程与句柄

- 只统计当前 Windows 会话中、路径与已验证客户端一致的进程树；不结束微信或企业微信。
- 句柄释放只限于白名单互斥锁与精确客户端路径的 `lock.ini`，不是任意句柄关闭器。

### 注册表

- 运行期临时修改仅限当前用户下企业微信 `multi_instances`，修改前先落盘恢复事务。
- 正常、崩溃或断电后只在当前值仍等于助手临时状态时恢复；第三方已写入新值时保留新值。
- 其余注册表写入仅是当前用户的卸载登记；无 `Run/RunOnce`、服务、计划任务或驱动持久化。

### 文件与删除

- 运行数据均在程序目录 `data`，并拒绝将数据目录指向符号链接或目录联接。
- 完整清理使用安装/绿色/发布/源码专用标记、精确结构、解析后路径、受保护目录拒绝和链接检查。
- 未发现针对磁盘根、用户主目录、Windows 目录或无标记任意路径的递归删除。

### 构建与供应链

- 业务程序无 NuGet 包和第三方运行 DLL；编译时无自定义下载、预构建/后构建 Shell 命令或隐藏载荷。
- GitHub Actions 仅有 `contents: read`，官方 Action 使用明确提交哈希固定，并生成/验证 SPDX 2.2 SBOM。
- 项目无代码签名；这是已知信誉限制，不通过降低安全软件等级规避。

Windows Shell 身份实现依据 Microsoft 文档：
[Application User Model IDs](https://learn.microsoft.com/en-us/windows/win32/shell/appids) 与
[System.AppUserModel.ID](https://learn.microsoft.com/en-us/windows/win32/properties/props-system-appusermodel-id)。

- Windows 可能把用户手工固定的历史快捷方式保留为独立固定项；本程序不强行编辑任务栏固定数据。
- 腾讯未公开承诺第三方多开机制长期保持不变；微信/企业微信更新后可能需要调整兼容层。
- 未签名新哈希可能触发 SmartScreen 或安全软件信誉/启发式提示；这不能单独证明文件恶意或安全。
