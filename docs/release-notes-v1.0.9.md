# V1.0.9 — “开开助手”品牌与极简主界面

V1.0.9 为项目建立正式、统一且易输入的产品名称“开开助手”，并完成第一套独立品牌图形。主界面只保留
高频操作；原有说明没有删除，而是整理进“设置 → 软件介绍”。多开、按缺口补开、安全更新、腾讯签名
校验和企业微信注册表恢复机制均保持原有边界。

## 本版变化

- 新名称：面向用户统一显示为“开开助手”；内部可执行文件名与数据标记保持不变，保证旧版本原地升级。
- 新 Logo：两个交叠的圆角窗口表达并行运行与单独补开，提供透明 PNG、SVG 源文件和 16–256 像素
  Windows ICO。
- 主界面精简：移除标题区长句、应用区识别说明、闲置页脚提示及数量卡底部说明，重新平衡留白和卡片。
- 设置新增“软件介绍”：集中保留按目标补开、客户端自动识别/手动选择、误关补回及 1–10 窗口范围说明。
- 安装器、清理器、窗口标题、文件属性、开始菜单、桌面快捷方式和本地诊断报告统一采用新名称与图标。
- 从旧版覆盖安装时迁移已知旧快捷方式；只处理三个精确旧路径，遇到额外文件时不会递归清空旧目录。
- README 改为从下载、安装、第一次使用到补开、手动选择客户端、诊断和更新的完整教程。
- UI 回归矩阵扩展为 14 个场景，新增软件介绍页的日间与夜间快照。

## 不变的安全边界

- 不注入 DLL，不修改微信或企业微信文件，不读取聊天数据、账号或凭据。
- 自定义客户端必须通过文件名、产品信息和腾讯 Authenticode 签名校验。
- 企业微信注册表临时状态仍使用落盘恢复事务、启动恢复和外部冲突保护。
- 一键更新仍只接受本项目 GitHub Release，并要求 GitHub digest、`SHA256SUMS.txt` 和下载文件三方一致。
- 设置、主题、诊断、日志、恢复和更新证据仍只保存在程序目录的 `data` 文件夹。

## 发布文件

- `wechat_duokai-setup-v1.0.9.exe`：安装版及一键更新程序。
- `wechat_duokai-portable-v1.0.9.zip`：绿色免安装版。
- `wechat_duokai-cleanup-v1.0.9.exe`：独立完整清理器。
- `SHA256SUMS.txt`、SPDX SBOM、Windows CI 结果与 Kaspersky 原始扫描日志：发布核验证据。

项目未购买代码签名证书。首次运行可能出现未知发布者或信誉提示，请只从本项目 Release 下载并核对
SHA-256；明确告警应先隔离和核查，不应关闭安全软件或设置永久白名单。
