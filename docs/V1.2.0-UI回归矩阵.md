# V1.2.0 UI 回归矩阵

主界面最小仍为 901×513，三客户端卡片与共用数量卡片保持布局，没有新增外层滚动条。

主界面按钮依次切换日间、夜间、万圣日间、万圣夜，保持当前页面；单选卡、标题栏、活动图标、下一主题提示和保存状态同步。跟随系统仍在设置，安装/清理器保留日夜配对。

脚本产生 59 个演示样例：主界面、常规/主题/介绍、安装前后、清理器、信息/确认、文件/文件夹选择器，以及本版新增的退出确认和后台残留提示，含 1280×720、1920×1080、3440×1392。无真实账号、私人窗口或开发机路径。

交互检查完整循环不导航、设置页不变、选择同步、最小窗口五选项可见、文字边界与对比度。退出确认明确正常关闭/必要时结束后台和未保存风险；失败区分窗口与后台。

自动化测试入口共 66 项，另由全新 Windows CI 执行首次安装、覆盖升级、完整卸载三项流程检查；以同版本成功构建记录为最终证据。
