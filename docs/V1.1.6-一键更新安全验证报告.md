# V1.1.6 更新与安装安全验证报告

文档编号：`WD-V116-UPDATE-20260923`

## 范围

本版不改变 GitHub Release 的来源、规范下载地址、静态清单优先策略、SHA-256 校验、用户安装确认、独立安装身份或绿色版/安装版标记边界。重点修复自动检查的长期运行调度，以及手动覆盖安装的失败恢复。

## 自动检查

启动错峰结束后，助手每分钟只判断一次本地计划是否到期；没有到期时不发网络请求。成功检查后间隔 24 小时，失败时沿用 1/6/24 小时退避和服务端 `Retry-After`。设置开关在每次实际检查前重新读取，因此关闭后的待执行检查不会发出。手动检查始终由用户主动触发。

## 下载、校验与执行

1. 只接受固定仓库规范 Release 的安装包及 `SHA256SUMS.txt`；静态更新清单为不依赖 REST API 配额的主路径。
2. 本地缓存复用前重新核对文件长度、清单摘要、校验文件唯一记录及 setup 实际 SHA-256。
3. 启动独立安装程序前再次计算 setup 哈希；执行前仍显示确认框。
4. 当前目录必须有本项目专用安装版或绿色版标记，防止覆盖源码及任意文件夹。

## 手动安装事务

普通安装现在先在目标目录内暂存全部文件并验证主程序版本，再逐文件替换、保留旧文件备份。捕获到替换异常时反向恢复；新安装失败不留下有效安装标记。提交期间存在专用中断标记，助手看到该标记便拒绝启动，并提示重新运行正式安装包。这样可以防止断电后误运行新旧文件混合的程序。断电恢复需要重新执行安装包，不宣称能够在无人介入时自动完成覆盖或回滚。

本地自动测试覆盖不同替换步骤的故障注入、旧程序和 `data` 保留、首次安装失败清理以及中断标记后的原目录重试。正式发布还需核对全新 Windows CI 产物的哈希、静态清单、SBOM 和安全软件扫描结果。
