# 微窗助手 V1.2.0

发布日期：2026-11-04

- 全部退出升级为正常关闭、清理已核验关联后台、连续复查；处理短暂重启与迟到子进程，避免只看一次旧快照。
- 明确区分可见窗口、后台残留、访问受限、归属无法核验和检查异常，不再把无可见窗口的后台笼统称为“窗口未关闭”。
- 限定当前用户 SID 与会话、精确主路径、辅助名称白名单、腾讯签名、创建时间与父子链，保留无关同名进程、其他安装副本、其他用户和共享服务。
- 使用同一已核验原生句柄结束/等待目标，减少 PID 重用竞态；核验期间只读持有文件。不自动提权，不改变安全软件设置。
- 主界面右上角按钮依次循环“日间 → 夜间 → 万圣日间 → 万圣夜”，保持当前页面；“设置 → 主题”仍可跟随系统。
- 本地诊断增加最近退出计数；启动恢复异常安全失败并阻止新的企微临时注册表会话；关闭助手后不再回写启动/退出结果。
- 修复首次安装回滚遇文件占用时无法重试：保留安全中断标记并有限重试清理，释放占用后可在原目录重装。

关闭客户端不等于注销账号，也不会删除聊天；强制结束阶段可能丢失未保存内容。Windows/组织保护可能阻止结束进程，此时如实报告，不保证可以强行关闭任何进程。

正式包来自成功的全新 Windows CI，附哈希、静态更新清单、SPDX SBOM、验证资料和脱敏扫描记录。没有公共代码签名；扫描未检出不等于绝对安全。
