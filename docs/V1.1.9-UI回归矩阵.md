# V1.1.9 UI 回归矩阵

主界面保持 QQ、微信、企业微信顺序、共享目标数量及 901×513 最小尺寸，不加入外层滚动条。设置分为常规、主题、软件介绍。

主题页提供跟随系统、日间、夜间、万圣夜四张预览卡，支持键盘焦点与可访问名称。万圣夜采用统一的紫黑、暖橙和矢量南瓜；主程序、安装前后、清理器、信息/确认弹窗及文件/文件夹选择器均覆盖季节主题。

运行 `scripts/capture-ui-matrix.ps1` 生成本版 38 个截图，涵盖三种外观、主界面及各设置页、1280×720、1920×1080 与 3440×1392 尺寸。自动化主题页布局测试覆盖最小尺寸到超宽屏，检查四张卡片不超出面板。

公开截图仅使用 `C:\Apps\Tencent`、`C:\Apps\WechatDuokai` 与模拟窗口计数，不展示开发机真实目录；注入只在截图测试层执行，不改变正式应用行为。
