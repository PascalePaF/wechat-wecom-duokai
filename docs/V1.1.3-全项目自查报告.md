# 微窗助手 V1.1.3 全项目自查报告

文档编号：`WD-V113-AUDIT-20260920`

## 结论

V1.1.3 是 V1.1.2 的网络兼容小修复。新增代码只统一 GitHub 请求的代理选择与 TLS 下限，没有改变多开、
进程退出、企业微信注册表事务、设置存储、诊断内容、安装/清理范围或界面结构。没有新增服务器、遥测、
上传、远程配置、广告、账号读取或聊天数据访问。

## 变更范围

| `core/NetworkProxyPolicy.cs` | 解析规范 HTTPS_PROXY/HTTP_PROXY；TLS 1.2；统一 HttpClientHandler | 无持久化、无日志、无新域名 |

| `tests/Program.cs` | 代理 URI 接受/拒绝/凭据回归 | 无真实凭据进入源码或产物 |

## 网络与隐私复核

网络目标仍只有：

- `github.com/PascalePaF/wechat-wecom-duokai/releases/...`；
- 可选 `api.github.com/repos/PascalePaF/wechat-wecom-duokai/releases/latest`；
- GitHub 官方 `*.githubusercontent.com` / `release-assets.githubusercontent.com` 附件交付域。

代理地址来自当前进程环境，只交给 .NET `WebProxy`，不上传、不写入 `data`、不进入诊断报告。程序仍只在
自动检查开关开启或用户点击检查时联网，只有用户确认后才下载 SHA256SUMS 和 setup。

## 兼容与失败方式

- 环境代理合法：版本检查和下载通过代理。
- 环境代理缺失：保留 Windows/.NET 默认系统代理行为。
- 环境代理非法：忽略该环境值并使用系统默认，不把任意 path/query 当作代理。
- 代理不可达或 TLS 失败：显示连接失败，不执行任何下载文件；自动检查按 1/6/24 小时退避。
- 下载中断：删除 `.part`，不会执行不完整文件；用户可手动重试。

## 剩余风险

项目仍未商业签名；安全软件可能因低信誉、进程句柄和注册表行为给出启发式提示。代理或企业 HTTPS 扫描
软件可能改变连接行为；本版本提升常见环境变量代理兼容，但不能保证所有专有代理认证协议。失败时程序
不会放宽 TLS、域名或 SHA-256，用户仍可从浏览器打开不可变 GitHub Release 手动更新。
