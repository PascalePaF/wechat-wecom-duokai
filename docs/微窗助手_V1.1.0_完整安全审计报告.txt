微窗助手 V1.1.0 完整安全审计报告
==================================

报告日期：2026-09-20（Asia/Tokyo）
审计对象：PascalePaF/wechat-wecom-duokai V1.1.0 源码、进程退出边界、构建脚本、更新链与候选发布文件

一、结论摘要
------------

未发现后台上传聊天、账号、联系人、凭据、诊断或本地路径的代码；未发现 DLL 注入、远程线程、客户端
文件修改、键盘记录、屏幕抓取、持久化服务、计划任务、隐藏驱动或远程命令执行链。

V1.1.0 新增微信/企业微信分端“全部退出”。该能力必须由用户点击对应卡片并在默认选择“否”的确认框中
同意，不能由版本检查、安装、更新、定时器或程序启动自动触发。退出选择只接受当前 Windows 会话中、
完整可执行路径与已验证官方客户端完全一致的进程。相对 V1.0.11，本版新增了明确的进程终止能力，
但没有扩展为任意进程管理器，也没有管理员提权。

二、退出流程与风险控制
----------------------

InstanceManager 首先按微信/企业微信的允许进程名枚举候选，再强制要求当前 Windows 会话和完整客户端路径
一致。Windows 关闭层取得 PID 后不会直接信任旧快照，而是重新打开进程并再次验证实时会话与 MainModule
路径；读取失败、已退出、PID 状态变化或路径不同均跳过。

对通过验证的进程先调用正常窗口关闭并等待 2 秒，让客户端自行保存和退出。等待后只对仍存在、且再次
通过同一实时验证的进程调用 Kill；不提升权限，访问被拒绝时不绕过。操作结束后重新按根进程统计窗口，
仍有窗口时向用户报告失败，不伪报“全部退出”。

关闭客户端可能丢失尚未发送的文字、未完成文件传输或其他未落盘状态，因此确认框明确提示风险并默认
选择“否”。该功能只关闭程序，不会主动注销账号；账号是否保持登录由官方客户端自身决定。

三、网络与隐私边界
------------------

客户端只在用户允许启动检查或主动检查时读取 api.github.com 上本项目正式 Release。只有用户确认一键更新后
才下载同一 Release 的 SHA256SUMS.txt 与精确版本 setup。程序不上传本地内容。源码中未发现其他 HTTP 服务、
Socket/WebSocket/FTP、遥测 SDK、广告 SDK、动态代码下载或未知域名。

程序不读取聊天数据库、账号、Cookie、联系人、凭据、剪贴板、摄像头、麦克风或屏幕。诊断仅写程序目录
data/diagnostics，不自动上传。

四、多开、句柄与客户端边界
--------------------------

客户端路径必须符合允许文件名、产品元数据和有效腾讯 Authenticode 签名。实例统计、补开和退出都限制为
当前会话与精确官方路径。补开使用的句柄释放仍只匹配已知微信/企业微信互斥锁名和精确 lock.ini；未扩展
为任意句柄关闭。未发现 CreateRemoteThread、WriteProcessMemory、VirtualAllocEx、DLL 注入或客户端补丁。

五、注册表与崩溃恢复
--------------------

企业微信 multi_instances 修改在短期启动会话前写入 data/recovery 落盘事务；正常/异常结束后仅在当前值
仍等于助手临时状态时恢复。第三方已写入新值时保留新值。退出功能不写注册表。其余注册表写入只有当前
用户卸载登记；没有 Run/RunOnce、计划任务、服务或驱动持久化。

六、数据、更新与删除边界
------------------------

设置、主题、诊断、恢复、日志和更新证据位于程序目录 data。程序拒绝数据目录链接/联接。更新前要求 GitHub
asset digest、SHA256SUMS 和下载文件 SHA-256 三方一致，再验证计划、父进程、时效、目标身份和文件哈希。
安装版/绿色版使用同卷暂存、逐文件备份和逆序回滚，data 不进入替换清单。

完整清理对安装目录、绿色包、发布目录和可选源码分别验证专用标记、精确结构、解析后路径与链接属性；
拒绝磁盘根、系统目录、未标记目录和目录联接。客户端退出与完整清理使用不同入口和不同目标校验。

七、构建与供应链
----------------

业务程序无 NuGet 包和第三方运行 DLL。项目文件没有预构建/后构建 Exec、远程导入、隐藏下载或不明载荷。
版本唯一来源为 Directory.Build.props。GitHub Actions 仅 contents: read，官方 Action 固定到明确提交，并在
全新 Windows Server 2022 上重建、测试、复核 SHA-256、生成并验证 SPDX 2.2 SBOM。

八、发布验证与已知限制
----------------------

发布前执行 Release 重建、全部自动测试、14 场景 UI 回归、本地重复确定性组包、SHA-256 复核、GitHub-hosted
Windows 重建、SPDX 2.2 SBOM 生成/验证，以及 Kaspersky 对最终 CI 工件原件扫描。未检出只是证据，不是
绝对安全保证。

项目没有公共信任 Authenticode 签名，Windows 或安全软件可能提示未知发布者、低信誉或启发式告警。不应
盲目忽略或关闭防护；应对照正式 Release 哈希、源码标签、CI、SBOM 和扫描日志。腾讯未承诺第三方多开、
进程模型或窗口关闭行为长期稳定；客户端变化时本工具选择失败关闭，不放宽到仅凭进程名终止。
