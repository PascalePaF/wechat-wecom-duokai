## 重点断言

- 设置页同时显示启动检查开关、更新说明、状态文本、进度条区域、检查按钮和按需出现的一键更新按钮。
- 没有可信新版本时，一键更新按钮为折叠状态，不留下空白占位。
- 下载时状态文本与进度条在原卡片内显示，不增加滚动条或弹出后台窗口。
- 日间和夜间主题中按钮、进度、说明文字和危险/成功状态保持可读。
- 901×513 下所有交互控件位于可视区域；最大化与超宽屏继续整体按比例放大。
- 主界面只显示一组目标数“− / 数字 / +”，不再出现微信、企微两行数量控件。
- 安装器自动更新模式复用现有精致样式，明确显示目标目录、回滚说明和更新状态。
