# V1.1.11 UI 回归矩阵

保留普通日间、夜间；万圣日间与万圣夜覆盖软件标识、活动窗口图标、背景、卡片边框、按钮和输入控件。主界面最小尺寸仍为 901×513，五个主题选项在同页显示，不增加外层滚动条。

完整截图脚本生成 51 个演示样例，覆盖主界面、常规/主题/介绍、安装前后、清理器、信息/确认和路径选择器，包含 1280×720、1920×1080、3440×1392。

新增视觉回归检查普通主题恢复、原生窗口图标、矢量资源和渐变对比度、控件文字边界以及装饰不接收鼠标/焦点。装饰无计时动画，绘制随窗口尺寸和既有比例缩放。

自动化测试入口共 54 项，新增的两项分别覆盖三种可执行身份下的主题往返和原生图标，以及节日日夜、四种尺寸、四个页面组合的布局。另由 Windows CI 独立执行首次安装、覆盖升级与完整卸载三项流程检查。
