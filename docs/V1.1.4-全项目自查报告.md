# 微窗助手 V1.1.4 全项目自查报告

文档编号：`WD-V114-AUDIT-20260921`

## 结论

V1.1.4 是一次范围明确的 UI 回归修复。目标数量卡片恢复 V1.0.10 的内部结构，同时保留 V1.1.0 以后
新增的外框对齐、全部退出、页脚实时数量和 V1.1.3 更新网络修复。没有新增网络目标、权限、遥测、
数据采集、进程控制、注册表写入、文件删除或自动执行路径。

## 代码变更复核

| 区域 | 变化 | 结论 |
| --- | --- | --- |
| `duokai/MainWindow.xaml` | 目标数量卡片恢复五段居中结构和两行说明 | 纯布局与静态文案 |
| `tests/Program.cs` | 固化五段尺寸、精确文案、外框等高与多分辨率断言；临时 EXE 清理增加等待重试 | 不进入正式程序 |
| 版本与打包资料 | 统一升级至 1.1.4 | 发布身份一致 |
| `core` | 无业务代码变化 | 多开、更新、安全边界不变 |
| `installer` / `cleanup` | 仅版本清单变化 | 安装和删除范围不变 |

## UI 复核

- 901×513 日间与夜间主界面和 V1.0.10 数量卡片逐项对比；
- 标题、范围说明、计数器和保存提示的顺序、间隔、字号恢复；
- 左右外框继续同顶同底；
- 1280×720、1920×1080、3440×1392 继续统一比例缩放；
- 设置、软件介绍、安装器和清理器无回归。

## 安全复核

- 不注入 DLL，不写微信/企业微信内存或客户端文件；
- 自定义客户端仍需腾讯签名验证；
- 企业微信注册表修改仍使用落盘事务、崩溃恢复和外部冲突保护；
- “全部退出”仍需用户确认，只处理当前会话和精确已验证路径；
- 诊断与配置仍只写程序目录 `data`；
- 更新仍只信任固定 GitHub 仓库、静态清单和多重 SHA-256。

结论：未发现后门、隐蔽上传、远程控制、凭据采集或由本轮 UI 调整引入的新安全风险。
