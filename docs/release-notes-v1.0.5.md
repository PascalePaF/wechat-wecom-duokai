# V1.0.5 — 实时状态、设置中心与可复核构建

V1.0.5 把日常状态和偏好设置收回到一个更清晰的主窗口中，同时加强企业微信注册表恢复的并发安全，
并新增可在 GitHub 上独立复跑的 Windows 构建、测试、哈希与 SBOM 门禁。

## 新增与改进

- 左下角以两行实时显示“当前微信窗口 x 个”和“当前企业微信窗口 x 个”。
- 右下角最右侧加入设置按钮；设置页与主界面在同一窗口切换，不增加滚动条。
- 主题支持跟随 Windows、固定日间、固定夜间；页眉仍保留快速日/夜切换。
- 可设置是否在启动时自动检查 GitHub 新版本，并可手动立即检查。
- 更新检查只读取版本号；软件不会在客户端内静默下载、安装或执行更新。
- `multi_instances` 恢复加入外部冲突保护：第三方在启动期间写入的新值不会被旧快照覆盖。
- 新增干净 GitHub 托管 Windows 构建：Release 重建、完整测试、SHA-256 复核、SPDX 2.2 SBOM
  生成与验证、构建工件上传。
- UI 回归增加设置页日间/夜间最小尺寸，共 12 个自动截图场景。

## 下载文件

- `wechat_duokai-setup-v1.0.5.exe`：当前用户安装版，可选择安装目录。
- `wechat_duokai-portable-v1.0.5.zip`：绿色免安装版。
- `wechat_duokai-cleanup-v1.0.5.exe`：独立完整清理器。
- `SHA256SUMS.txt`：关键发布文件 SHA-256。
- `manifest.spdx.json`：SPDX 2.2 软件物料清单。
- `kaspersky-scan-v1.0.5.txt`：本机 Kaspersky 对最终发布目录的原始扫描日志。

本项目按既定决定不进行付费、自签或托管代码签名。请只从本仓库 Releases 下载，核对标签和 SHA-256，
