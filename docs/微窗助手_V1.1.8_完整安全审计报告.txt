微窗助手 V1.1.8 安全修复与隐私检查报告
审计日期：2026-10-30

一、检查范围
源码中的更新发现与下载、腾讯客户端身份校验、本地持久化、安装事务和现有回归测试，以及本版发布资料和附件。

二、本版确认并修复的问题
1. ResponseHeadersRead 的请求超时不能覆盖后续流式正文，停滞连接可能长期占用“检查中/下载中”状态。本版对整个操作施加可取消的时限，并限制 API 正文大小。
2. 原发布者检查仅搜索证书 Subject 内的 Tencent 子串。本版在 Windows 验证签名有效后，核对法定组织 O 字段的完整允许值，拒绝相似名称和缺失组织字段。
3. 数据目录部分分支只检查末级目录，未覆盖上级目录联接和文件链接。本版逐级检查，拒绝路径重定向，并对缓存、设置等使用唯一新建文件及原子替换。
4. 诊断报告原本包含完整本机路径，且相同秒数可能覆盖。本版默认输出目录占位符，文件名增加随机后缀。
5. 当前发布资料原本包含开发机路径。本版对文字资料脱敏，界面截图使用演示数据，编译记录映射到统一源码路径，并新增发布检查。

三、隐私边界
诊断报告由用户主动生成，只保存在 [安装目录]\data\diagnostics。默认隐藏程序数据目录及客户端完整路径，不读取聊天、账号或凭据。分享前仍应复核内容。
原始完整扫描日志只保留在本地，公开扫描记录应标注“路径已脱敏”，保留检测结果和核验所需信息。

四、剩余限制
本版未重写已有提交、标签和其他人的克隆，也未在原版本号下静默替换旧安装包。旧的目录名称可能仍在历史记录中。
无公共 Authenticode 代码签名；下载校验依赖本项目 GitHub 及其 HTTPS 交付。发布账号失陷不在本地 SHA-256 校验能独立解决的范围内。
同一 Windows 用户拥有相同权限的恶意程序仍可能竞争修改用户可写的目录；本版增加路径与链接防护，不将此描述为对本机管理员的隔离沙箱。

五、复核方式
运行 build-release.ps1，执行现有业务回归和新增安全用例；GitHub Actions 在全新 Windows 环境验证构建、安装、升级、卸载、哈希、SBOM 和发布隐私检查。
报告中的修复范围不等于“没有任何漏洞”的保证，实际验证结果以同版 CI 和扫描附件为准。
