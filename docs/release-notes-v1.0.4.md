# V1.0.4 — 比例界面与企业微信三开兼容模式

V1.0.4 重点修正最大化后的界面比例，并补上企业微信超过两个实例的安全兼容路径。主界面以用户给出的
901×513 构图作为最低尺寸，移除外层滚动条；放大后所有视觉元素统一缩放，3440×1392 超宽屏也会
填满工作区。

## 主要变化

- 目标数量在所有尺寸下保持最右侧，不再切换为上下排列。
- 字体、图标、按钮、输入框、圆角、阴影和间距随窗口统一等比放大。
- 企业微信 `5.0.11.6018` 已真机验证三个根实例同时运行。
- 不再永久写入企业微信 `multi_instances`：启动前保存，完成/失败/取消后恢复原值与类型。
- 企业微信三开及以上时临时避开只支持双开的注册表提示，仅释放已知独占互斥锁后增量补开。
- 新增注册表恢复、企业微信 1→3、启动时序和 3440×1392 比例回归测试。
- 保留日间/夜间主题、可移动原生标题栏、运行中安全覆盖、本地诊断和浏览器下载更新。
- 本项目继续保持未签名；请从本仓库 Release 下载并核对 SHA-256，不要因启发式告警而关闭安全软件。

## 下载文件

- `wechat_duokai-setup-v1.0.4.exe`：当前用户安装版，可用文件夹选择器指定安装位置。
- `wechat_duokai-portable-v1.0.4.zip`：绿色免安装版，解压完整目录后运行 `wechat_duokai.exe`。
- `wechat_duokai-cleanup-v1.0.4.exe`：独立清理器，可保留源码清理程序，也可在额外确认后清理源码。
- `SHA256SUMS.txt`：安装器、清理器、绿色 ZIP、主程序与 Core 的哈希。
- `kaspersky-scan-v1.0.4.txt`：Kaspersky 对最终发布目录的原始扫描日志。

## 重要边界

企业微信只在当前官方 `5.0.11.6018` 上实测到三开；4–10 是可请求范围，不是对所有历史或未来版本的
承诺。程序不注入、不修改腾讯客户端、不结束现有登录实例。若新版本改变锁机制，程序会报告未达到目标，
不会自动扩大操作范围。
