# V1.0.8 — 舒适夜间主题与精简主界面

V1.0.8 集中优化夜间使用体验，并把低频工具入口收回设置页。核心多开、增量补开、企业微信注册表保护、
本地数据边界以及 V1.0.7 的安全更新链保持不变。

## 界面改进

- 夜间主题重新校准为低亮度、低饱和度配色：金色主按钮、绿色状态、蓝色提示、警告/危险色和边框都更柔和。
- 夜间正文从高亮暖白改为较柔和的中性灰白，在保证可读性的同时减少大面积高亮刺激。
- 微信和企业微信图标外层不再使用写死的浅色底；两块背景会随主题切换，夜间分别使用深墨绿与深蓝灰。
- 日间主题原有配色保持不变。
- 主界面右下角只保留“设置”，移除“诊断”和“发布版本”两个低频入口，页脚更简洁。
- 设置页新增“本地诊断 / 生成报告”，报告仍只写入程序目录下的 `data\diagnostics`，不会上传。
- GitHub“发布版本”入口继续位于设置页的“版本与更新”区域，与检查更新和一键更新放在一起。

## 回归与安全

- 新增夜间主题自动断言，限制状态色和图标背景亮度，避免以后重新引入刺眼浅色。
- 继续验证 901×513 最小界面、无滚动条、全窗口比例缩放以及日间/夜间 12 场景截图矩阵。
- 一键更新继续要求 GitHub 附件摘要、`SHA256SUMS.txt` 和本机下载文件三方 SHA-256 完全一致。
- 所有持久运行文件仍位于程序目录的 `data`；本版本没有新增遥测、后台上传、服务、驱动或开机启动项。
