## 验收点

- 主窗口、安装器、清理器以及系统 EXE 图标使用同一套品牌图形，不再显示“ 双 / 装 / 卸 ”文字占位符。
- 主界面标题为“开开助手”，次级文字只保留“微信 · 企业微信”。
- 主界面不再出现长功能口号、客户端定位说明、闲置启动提示和数量卡底部帮助文字。
- 被移除的功能说明完整出现在“设置 → 软件介绍”，并提供三步使用方法。
- 常规设置与软件介绍可在同一窗口切换，返回主界面后仍保持高频操作优先。
- `901×513` 下应用卡片、目标数量和页脚均不裁切；窗口只能放大，不能低于最小尺寸。
- `1280×720`、`1920×1080` 与 `3440×1392` 下使用同一非缩小比例，所有内容一起放大并填满窗口。
- 日间和夜间主题下 Logo、正文、按钮、状态色和图标背景均具有足够区分度且没有刺眼白边。
- 安装器仍需安装完成后明确点击“确认并启动”；清理器仍显示两种清理范围与安全校验提示。
